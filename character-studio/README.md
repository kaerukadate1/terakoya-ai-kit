# キャラクター設計ツール

寺子屋AI 第4回ワークショップの試作 v0.1.0。

自分の仕事に合うキャラクターの役割・ペルソナ・判断基準を整え、ChatGPT Workの専用プロジェクトで使う指示と最初の依頼文を作ります。

## できること

1. 仕事・対象顧客・任せたいことを入力。
2. 秘書、広報、企画、調査、資料制作、自由設定から役割を選択。
3. 名前、話し方、世界観、任意の画像を設定。
4. 判断・質問・完成条件・本人承認の境界を設定。
5. プロジェクト指示と初仕事の依頼文をコピー・Markdown出力。
6. キャラクターの保存・再編集・複製・削除・JSONバックアップ。

ChatGPTへの相談は、確認した入力を依頼文にして別タブへ渡す方式です。自動実行・自動返送はしません。JSON回答は依頼IDと対象を照合し、本人の確認後に取り込みます。初仕事の継続利用は、設定したプロジェクト内のWorkで行います。

## 境界

制作ツールは設計・保管の画面、仕事を実行する主体はChatGPT Workです。プロジェクトへの自動登録、新しい独立エージェントの登録、機能・権限の追加、常駐実行、定期実行は含めません。APIキーは不要です。画像は任意のアップロード、画像制作の依頼文はコピーできます。

保存先はこのブラウザのlocalStorage。端末・ブラウザ・URLが変わると自動で同期しません。秘密情報は入れず、JSONバックアップを利用してください。保存に失敗した場合は未保存として表示します。初期一覧は空です。
