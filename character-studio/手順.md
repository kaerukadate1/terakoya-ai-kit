# 使い方

1. 開始文.txtをChatGPT Workへ貼り、ツールを作る。
2. 自分の仕事と任せたいことを入力する。
3. 役割、ペルソナ、世界観、仕事のルールを調整する。名前は必須、画像は任意。
4. 「試す・設定する」でプロジェクト指示を確認してコピーする。
5. ChatGPTで専用プロジェクトを作り、その指示へ貼る。必要な事業資料を追加する。登録は本人が行う。
6. 「最初の仕事」でゴール・資料・出力を入力し、依頼文をコピーして、そのプロジェクト内のWorkで実行する。
7. 実行結果を記録し、必要なら設定を直してプロジェクトの指示も更新する。
8. キャラクター一覧へ保存する。バックアップJSONは別端末への移行にも使える。

「ChatGPTで試す」は依頼文付きの新しい会話を開きます。既存プロジェクトへ自動で移動・登録しません。Workを選び、内容を確認して実行してください。相談のJSONは内容を確認して取り込みます。

一覧からの削除は、このツール内の設定だけが対象です。ChatGPTのプロジェクトは削除されません。
