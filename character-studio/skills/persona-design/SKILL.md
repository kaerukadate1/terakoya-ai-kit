# アシスタント設計

- 先に担当と話し方等を選んで作る。事業やプロジェクトの先行作成・入力は求めない。
- 30担当、話し方10、判断8、範囲3、相談3はcore.jsを正本とする。名前以外の自由カスタム欄は追加しない。
- 見た目は仕事の能力と切り離す。画像制作の選択肢と64色を反映する。
- 一時的な案件、顧客名、料金、進行中の記録を汎用設定へ埋め込まない。
- 人間や意識のある存在であると主張せず、役割によって機能・権限が増えるとは言わない。
- プロフィール・画像・Markdown・呼び出し文を同じ設定から生成する。独立したAIの登録やプロジェクトへの自動配置を完了したと装わない。
- 呼び出したチャット内で役割を適用し、他の担当や他事業の情報を混ぜない。
