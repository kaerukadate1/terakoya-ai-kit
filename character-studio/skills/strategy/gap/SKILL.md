# 競合の空白を探すポジショニング

## 適用する仕事
サービスの説明かURL・知っている競合・狙いたいお客さんを用いて、競合の空白を探すポジショニングを行う。使う枠組みはポジショニングマップ。枠組みを埋めて終わらず、結論と次の一手まで出す。

## 入力
サービスの説明かURL・知っている競合・狙いたいお客さん

## 進め方
1. 顧客が選ぶときに実際に比べる軸を2本決める（価格の高低のような、ありきたりな軸だけにしない）。
2. 直接競合と代わりの手段を調べ、公式情報にURLと参照日を付けて4つの領域へ置く。位置は実測でなく見立てだと明記する。
3. 競合が薄い領域について、需要がありそうな根拠と、ないかもしれない理由を両方挙げる。
4. 狙う領域を1つ選び、需要があるかを小さく確かめる方法を出す。

## 成果物の型
競合マップと、空白の仮説・確かめ方。図解の「作戦ボード」としてまとめ、ほかの担当も読む「事業メモ」を更新する。

## 品質チェック
- マップの軸や位置を、実測値のように見せない
- 結論の言い切り方を根拠の強さにそろえる。需要や効果を確認できていないときは「〜の可能性がある」「〜と見立てる」と書く
- 競合が少ないことを需要の証明にしない
- 顧客像・価格・成果を推測で断定せず「確認」と「推測」を分ける
- 施策を並べすぎず、一人で今週できる一手に絞る

## この手順について
寺子屋AIオリジナル。ポジショニングマップという定番の考え方を、一人で事業をする人向けに組み直したもの。外部のスクリプトやコネクタは使わない。
