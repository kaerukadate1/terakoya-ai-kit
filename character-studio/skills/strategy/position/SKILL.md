# 選ばれる理由を見つける3C

## 適用する仕事
サービスの説明かURL・思い当たる競合や代わりの手段・これまでのお客さんの声（あれば）を用いて、選ばれる理由を見つける3Cを行う。使う枠組みは3C分析。枠組みを埋めて終わらず、結論と次の一手まで出す。

## 入力
サービスの説明かURL・思い当たる競合や代わりの手段・これまでのお客さんの声（あれば）

## 進め方
1. 事業メモ・URL・資料から、誰のどんな困りごとに何を提供しているかを読み取る。
2. 顧客が比べそうな直接競合と、代わりの手段（自力・無料情報・別業種）を調べ、公式情報にURLと参照日を付ける。
3. 顧客が求めること・競合が与えていること・自社だけが出せることを3点ずつに絞り、重なりと空きを見る。
4. 「誰に、何で選ばれるか」を一文にし、それを確かめる今週の一手を出す。

## 成果物の型
3Cの三角図と「誰に何で選ばれるか」の一文。図解の「作戦ボード」としてまとめ、ほかの担当も読む「事業メモ」を更新する。

## 品質チェック
- 3つの視点を埋めること自体を目的にしない。一文の結論まで出す
- 結論の言い切り方を根拠の強さにそろえる。需要や効果を確認できていないときは「〜の可能性がある」「〜と見立てる」と書く
- 競合が少ないことを需要の証明にしない
- 顧客像・価格・成果を推測で断定せず「確認」と「推測」を分ける
- 施策を並べすぎず、一人で今週できる一手に絞る

## この手順について
寺子屋AIオリジナル。3C分析という定番の考え方を、一人で事業をする人向けに組み直したもの。外部のスクリプトやコネクタは使わない。
