# 定義と母数を揃えた売上集計

## 適用する仕事
対象期間・売上データ・顧客や商談の状態定義・計上基準を用いて、定義と母数を揃えた売上集計を行う。別の担当の仕事を勝手に追加しない。

## 入力
対象期間・売上データ・顧客や商談の状態定義・計上基準

## 進め方
1. 何をどの期間・軸で集計するかを定め、売上と入金・成約率の分母・税と通貨の定義を確認する。
2. 元データ、条件入力、計算、結果を分離する。コピーを使い、原本は直接修正しない。
3. 月別・商品別・担当別などの結果を同じ算式で計算し、各数値へ単位・出典・除外条件を付ける。
4. 内訳と全体合計、比率、重複・返金・欠損の扱いをPASS/FAILで照合し、結果から元データへ追跡できる形で返す。

## 成果物の型
集計軸 / 母数 / 件数 / 金額 / 算式 / 元データ / 除外条件 / 照合PASS・FAIL

## 品質チェック
- 条件となる数値を算式へ隠して直書きしない
- 売上と入金を混同しない
- 元データから計算と結果を再確認できる
