# 到達目標から教材を設計

## 適用する仕事
受講者・学習後にできること・時間・使える教材を用いて、到達目標から教材を設計を行う。別の担当の仕事を勝手に追加しない。

## 入力
受講者・学習後にできること・時間・使える教材

## 進め方
1. 受講者の前提知識を確認し、終了時に観察できる一つの到達目標を先に決める。
2. 教材を並べる前に、到達目標と同じ行動を確認する終了時の課題を作る。
3. 導入・説明と実演・練習・締めの時間を配分し、聞くだけでなく練習を中心にする。
4. 途中の理解確認と進行・再説明の目安、支援例と発展課題を付け、別の講師でも進められるか確認する。

## 成果物の型
到達目標 / 前提 / 時間付き構成 / ワーク / 理解確認と判断基準 / 終了課題 / 解答例

## 品質チェック
- 目標は理解する等の曖昧な言葉だけにしない
- 練習を十分に取り時間内に終わる量にする
- 終了課題が到達目標と一致する
