# 価格と売り方の設計

## 適用する仕事
商品・サービスの内容・今の価格・似たサービスの価格・目標を用いて、価格と売り方の設計を行う。別の担当の仕事を勝手に追加しない。

## 入力
商品・サービスの内容・今の価格・似たサービスの価格・目標

## 進め方
1. 事業の種類・今の価格・似たサービスの価格帯・目標を確認し、価格帯にはURLと参照日を付ける。
2. 何をまとめて売るか・何に対して払ってもらうか・いくらにするかの3つに分けて、今の状態を整理する。
3. お客さんが得る価値を基準に価格を考え、松竹梅のような選びやすい段階を検討する。原価や競合の価格だけで決めない。
4. 何を売るか・いくらか・何に払うか・どう見せるかの4つの面のうち、変えると一番効く一箇所と、まず新しいお客さんから試す進め方を出す。

## 成果物の型
売り方の設計図（4つの面）/ 変える一箇所 / 価格の根拠 / 試し方

## 品質チェック
- 安すぎる価格は手応えを見誤らせ、後で上げにくいと伝える
- 競合や原価だけを基準にしない
- 売上や申込数を約束しない
- 価格は課金単位・適用商品・期間をそろえ、不明なら換算や最安順位を付けない
