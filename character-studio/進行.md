# 第4回ワークショップの進行

テーマは「自分だけのAIアシスタントを作ろう」。先に事業やプロジェクトを作らず、担当・話し方・仕事の方針・見た目の組み合わせを楽しむ。

1. スタータープロンプトでツールを作る。
2. 30担当から1つ選び、名前と仕事の進め方を決める。
3. 見た目を選び、希望者はChatGPTでプロフィール画像を作る。
4. 4点セットを一覧へ保存し、別の担当も作る。
5. Markdownを添付し、短い呼び出し文で担当として使う。プロジェクトがある人は、その資料へ追加してもよい。

目標は設定を作って持ち帰れること。初仕事は短い任意の体験として扱う。定期実行、外部送信、認証設定は講座の必須工程にしない。
