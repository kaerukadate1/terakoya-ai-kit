# 第4回の進め方

目的は「キャラクター設定を作る」だけでなく「その担当者へ仕事を1つ任せ、結果を見て調整する」こと。

1. 自分の仕事と任せたいことを整理する。
2. 役割とペルソナを作り、判断・完成条件・確認する境界を決める。
3. 専用プロジェクトへ指示を登録する。
4. Work内で実行・確認できる、小さく完結する仕事を依頼する。
5. 実際の成果物と未達を確認し、設定の改善点を記録する。

初回の題材は、資料や案内文、根拠付き比較など、利用環境で完結するものを選ぶ。動画生成など、必要な実行手段が未確認のものを全員必須にしない。

名前や世界観は楽しめる範囲で設定するが、機能追加や成果の保証とは説明しない。定期実行は補足に留め、今回は設定しない。
