# 開発と配布

編集元はcharacter-studio/。app/が画面、prompts/がビルドプロンプト、skills/が固有スキル、tests/が検証。releases/character-studio-v1/は生成先で、直接編集しない。

```sh
node scripts/generate-tool-release.cjs character-studio --write
node scripts/generate-tool-release.cjs character-studio --check
node --test character-studio/tests/*.test.cjs
node --test tests/*.test.cjs
node scripts/verify-entrypoints.cjs
```

ローカルでapp/をHTTP配信し、PCと390pxで入力、保存、再読込、コピー、書き出し、JSON照合、削除確認を検証する。外部通信は本人がChatGPTを開く操作だけ。URL入力は本文取得を意味しない。

実ユーザーの設定、画像、下書き、実行記録、Sites識別情報を公開キットへ入れない。初期キャラクターは空にする。既存の4ツールの配布実体を変更しない。
