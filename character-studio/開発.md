# 開発と検証

正本はcharacter-studio/app/。リリースはnode scripts/generate-tool-release.cjs character-studio --writeで生成する。

- node --test character-studio/tests/core.test.cjs
- node scripts/generate-tool-release.cjs character-studio --check
- node scripts/verify-entrypoints.cjs
- node character-studio/scripts/serve.cjs（既定8834）

ブラウザで5カテゴリーと各6担当、10/8/3/3選択、64色ずつ、名前だけでの保存、画像取り込み、Markdownダウンロード、呼び出し文コピー、再読込、複製、検索、削除確認、バックアップ追加を確認する。PC・モバイル幅で文字切れ・はみ出しを確認する。

旧localStorageキーは保持し、v1移行では原本をterakoya-character-studio-v1-before-v2に残す。壊れた既存データは上書きせず自動保存を停止する。課金APIや同期バックエンドは追加しない。

保存対象はプロフィール・画像・Markdown生成元・呼び出し文生成元を持つ一つの設定レコード。旧事業の情報は移行保管欄だけに残す。画像生成は外部ChatGPTへの明示操作と手動取り込みであり、自動返送しない。
