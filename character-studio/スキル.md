# 制作時に読むスキル

- skills/persona-design/SKILL.md: 汎用のアシスタント設定と選択肢。
- skills/work-execution/SKILL.md: 担当範囲、完成条件、承認境界。
- skills/work-return/SKILL.md: 画面操作をしない、同じSiteへのファイル返送。
- skills/roles/<担当ID>/SKILL.md: 30担当それぞれの専門手順。原典とMITライセンスは各references/、取得記録はsources.lock.json。選んだ担当分が設定Markdownへ入る。
- ../lp/skills/terakoya-web-design/SKILL.md: 既存ツールと揃えた画面設計。

ビルド時の制作指針と、設定ファイルへ組み込む担当別手順は区別する。参加者のChatGPTに外部スキルや実行権限が自動インストールされるわけではない。担当の手順は自己完結したMarkdownとして、本人が利用したいチャットへ添付し、仕事を依頼する。
