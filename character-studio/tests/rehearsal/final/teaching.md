# パン生地の扱い方｜20分教材の設計草案・技術部分は保留

**現状：実技教材の完成は資料不足で保留です。** パン生地を扱う目標を、観察や質問だけの別目標へ置き換えません。

確定に必要な質問は3点です。
1. 対象のパンと工程は何ですか（こねる・分割・丸める等）？ 講師が正として使うレシピや実演資料をください。
2. 受講者が使える生地の状態・分量・道具と、講師が採点する動作・仕上がり基準は何ですか？
3. 衛生・アレルギー対応、子どもの同伴時の作業場所・見守り、講師が止める条件はどう定めていますか？

以下は独立して作成できる教材設計です。角括弧の項目が未確定で、現場投入できる技術原稿ではありません。

到達目標案：初心者が、講師の指定した［対象工程］で、［手の動かし方］を自分で行い、［講師基準の状態］に仕上げられる。
前提：3人の受講を想定。生地と道具の準備は開始前に済ませる設計ですが、利用可能な教材は未確認。20分で発酵や焼成までできるとは仮定しません。

| 時間 | 教材と進行 |
|---|---|
| 0〜2分 | 到達目標と終了課題を提示。実習前の注意事項を講師の確定ルールで確認 |
| 2〜5分 | 講師が［対象工程］を実演。動作を見せ、手元の観察点と完成基準を示す |
| 5〜11分 | 各自が実習1回目。講師は3人全員の動作と状態を確認し、1点に絞って修正を伝える |
| 11〜16分 | 実習2回目。指摘した動作を再実施。未達者は講師の再実演を見て同じ工程を練習 |
| 16〜19分 | 終了課題：各自が同じ工程を行い、講師の基準で動作・状態を評価 |
| 19〜20分 | 達成点と継続練習する点を各1つ伝える。帰宅後フォローは約束しない |

ワーク用紙：「対象工程［ ］／今回の動作の注意点［ ］／1回目の講師指摘［ ］／2回目に変えたこと［ ］」。
理解確認と進行判断：11分時点で［動作基準］を満たしていれば反復へ。未達なら再実演して、反復回数を減らしても終了課題の時間は確保します。支援例は動作を一段階ずつ講師の指示に合わせて行うこと。発展課題は同じ工程を助言なしでもう一度行うことです。工程により支援が不適切なら監修時に修正します。

終了課題の採点欄：［必要動作］を行えた／［基準の状態］になった。いずれも対象工程の技術資料が届くまで具体化できません。
解答例欄：［正しい動作順］→［基準に合う状態］。**技術的な解答例は未作成**です。一般的なこね時間・温度・加粉量を推測で埋めることはしません。
