# 売上と入金を分けて集計する｜初心者向け20分教材

## 到達目標・準備・演習のルール
**到達目標：受講者がA・B・Cの提供日と入金日を使い、10月・11月の売上と入金を別々に計算し、提示データの最終時点の未入金1件を金額付きで識別できる。**
初心者向け。使う物は紙と電卓だけです。講師は下のデータと問題を紙に写して配るか、読み上げ、受講者が記入します。配布・準備は開始前に済ませます。

この演習で使う定義（提供資料記載）：
- 売上：サービス提供が確定した対価。売上確定日で月を分ける。
- 入金：現金等を受領した記録。入金日で月を分ける。
- 税・費用は扱わない。現実の正式な会計判断へ拡張しない。

演習データ（すべて架空。未記載の取引・入金は足しません）：

| 取引 | 提供日・売上確定額 | 入金日・入金額 |
|---|---|---|
| A | 10/20・4500円 | 11/2・4500円 |
| B | 10/25・4500円 | 10/25・4500円 |
| C | 11/4・4500円 | 未入金 |

## 20分の講師進行
| 経過時間 | 内容・講師の言葉と行動 |
|---|---|
| 0〜3分：解説 | 「売上と入金は、同じ金額でも日付が違うことがあります。今日は売上には提供日、入金には受領日を使います」。紙を「売上」「入金」の2欄に分け、それぞれに10月・11月欄を作らせる。目標と終了3問を先に示す |
| 3〜7分：講師実演 | Aを使い「提供10/20なので10月売上4500円。入金11/2なので11月入金4500円」と別欄へ記入する。Aは10月時点では未入金だが、11/2以後の提示データでは入金済み、と日付を区別する。「Aを11月売上へ入れてよい？」と問い、提供日が10月なので入れないと確認 |
| 7〜15分：個人演習 | 7〜10分でA/B/Cそれぞれの売上月・入金月を表にする。講師は日付の振り分けを巡回確認。10〜15分で下の終了課題3問を独力で解く。途中で答えを一斉に提示しない |
| 15〜20分：振り返り | 15〜18分で解答と理由を提示し自己採点。18〜20分で誤答者は日付に戻って再計算、講師が再確認。達成者は発展課題へ。終了時に「提供日と入金日を別々に使う」と各自一言で振り返る |

## 個人演習シート
まず下を埋めます。未入金は空欄や0月でなく「未入金」と書いてください。

| 取引 | 売上に入れる月・金額 | 入金に入れる月・金額 |
|---|---|---|
| A | ＿＿ | ＿＿ |
| B | ＿＿ | ＿＿ |
| C | ＿＿ | ＿＿ |

終了課題（3問）：
1. **月別売上**：10月と11月の売上はいくらですか？ 各月に含めた取引名と理由も書いてください。
2. **月別入金**：10月と11月の入金はいくらですか？ 各月に含めた取引名と理由も書いてください。
3. **未入金**：提示データの最終時点で未入金なのは、誰のいくらですか？ 売上月と理由も書いてください。

## 解答例・理由・合格基準
分類表の正答：A＝10月売上4500円・11月入金4500円、B＝10月売上4500円・10月入金4500円、C＝11月売上4500円・未入金。

1. **10月売上9000円（A4500＋B4500）、11月売上4500円（C）**。入金がいつかに関わらず、それぞれの提供が確定した月に分けるためです。
2. **10月入金4500円（B）、11月入金4500円（A）**。実際の入金日を使い、未入金のCは含めないためです。
3. **Cの4500円が未入金**。11/4に提供が確定したので11月売上に入りますが、受領した記録がありません。Aは11/2に入金済みなので最終時点の未入金ではありません。

採点は1問1点、合計3点。問1・2は両月の金額と取引の根拠が正しければ各1点、問3はC・4500円・未入金の理由を示せば1点。**3点で到達**です。金額だけ合って日付の根拠を説明できなければ、該当問を支援後に再確認します。初回と支援後の結果は分けて記録します。

## 理解確認・誤答時の支援・発展
- 10分時点：Aの売上月と入金月が分かれていれば集計へ進む。同じ月に入れていたら、提供日を丸、入金日を四角で囲ませ、それぞれの欄へ戻す。
- 11月売上を9000円とした場合：Aは「11月に入金した」のであって「11月に提供した」のではないことを、10/20と11/2を指して再説明する。
- 11月入金を9000円とした場合：Cの入金欄が「未入金」であることを確認し、受領した取引だけを足し直す。
- Aも最終時点の未入金とした場合：基準時点を区別する。Aは10月末なら未入金だが、提示された11/2の入金を反映した最終時点では入金済み。Cの状態とは別にする。
- 2分の支援後も誤る場合：未達の問題と原因を記録し、後の追加練習へつなげる。20分内に達成したと装わない。

発展課題（早く終わった人）：「提示された全期間の売上合計−入金合計は？」解答は13,500−9000＝4500円。このデータではCの未入金4500円と一致します。別の取引を含む現実の帳簿へこの簡単な式を無条件に広げません。
