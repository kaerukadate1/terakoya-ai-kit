適用した手順：観察できる目標と終了課題を先に決め、20分を実演・反復練習・評価へ配分。レシピ固有の数値を補わず教材案を作りました。

# 初心者向け20分教材｜生地の変化を言葉にして講師へ確認する

資料制約：配合・パンの種類・工程・生地の扱い方の原資料がありません。以下は教室で使う教材の完成草案ですが、正しいこね方・成形・温度・時間を教える実技教材としての実施準備は未達です。安全に扱える教材と基準を講師が指定するまで実施しません。
到達目標：講師指定の生地の扱いを1回試し、「見た目または触った変化」と「次に確認したいこと」を各1点、自分の言葉で伝えられる。
前提：初心者3人。講師が指定・準備した生地と道具を使う想定。準備時間は20分外。子ども同伴時の作業場所・見守り、アレルギー・衛生条件は運営確認が必要です。生地の試食やオーブン操作はこの教材に含めません。

| 時間 | 講師の進行・ワーク |
|---|---|
| 0〜2分 | 「今日は上手に焼くことではなく、生地の変化を観察して確認できるようにしましょう」。終了課題を先に示す |
| 2〜5分 | 講師が指定した扱いを実演。見る点を1つ、触って確認する点を1つ示す。講師欄：扱い方［要記入］・観察基準［要記入］ |
| 5〜12分 | 各自実習。講師の指定した扱いを試し、前後の変化を記録。「さっきと比べて何が変わりましたか？」と巡回 |
| 12〜16分 | ペアまたは講師へ観察を伝え、指示に沿ってもう一度試す。3人目も必ず発言機会を持つ |
| 16〜19分 | 終了課題を各自実施し、講師が確認 |
| 19〜20分 | 「家で迷ったら、どの工程で何が起きたかを言葉にして確認しましょう」と振り返る。帰宅後相談の提供は約束しない |

ワークシート：「試した扱い：＿＿／扱う前：＿＿／扱った後：＿＿／確認したいこと：＿＿」。
理解確認：12分時点で各人が変化を1つ言えれば反復へ。言えない場合は講師が2つの見方を示して選んでもらい、次の3分を再観察に使います。全員の進度が遅ければ反復回数を減らし、終了課題3分を確保します。発展課題は「変化を見た目と手触りの2種類で説明する」。
終了課題：「指定された扱いを試した結果を1つ言い、講師に確認したいことを1つ質問してください」。合格基準は観察と質問を各1つ具体的に伝えること。パンの仕上がり品質を合格基準にしません。
解答例（実際の生地の正解ではなく発言形式の例）：「扱う前と後で表面の様子が変わりました。どの状態まで進めたらよいか、先生の見本と比べて確認したいです」。講師は実物に合った具体的な観察語を促します。
次の一手：講師が実演の扱いと判定基準を記入し、実際の生地で20分の試行を行う。配合や工程が届くまで教材の技術的正確さは検証できません。
