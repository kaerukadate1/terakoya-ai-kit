適用した手順：目的と残す条件を定め、構成→明瞭さ→具体性→自然さの順で編集。
根拠のない成果保証を外し、変更理由を照合しました。

編集済み原稿：
子どもと一緒に参加できるパン教室です。家庭用オーブンを使って、パン作りを学びます。

| 元表現 | 修正表現 | 修正理由 |
|---|---|---|
| 絶対に一日でパン職人になれます！ | パン作りを学びます。 | 職業能力・1日での習得・保証の根拠がないため、依頼通り誇張を除去 |
| 子連れの方にも優しい講座です | 子どもと一緒に参加できるパン教室です | 「優しい」を具体的な参加条件へ置換 |
| なし | 家庭用オーブンを使って | 提供された事業メモの学び方を具体化 |

事実の扱い：これは架空資料に基づく提案コピーで、実教室の確認済み事実ではありません。親しみやすさと参加歓迎の意図を維持。要確認：子どもの対象年齢・見守り・安全条件、家庭用オーブンの利用条件。次は教室担当がこの条件を確定してから使用。1週間相談、日時、実績は追加していません。外部出典・公開なし。
