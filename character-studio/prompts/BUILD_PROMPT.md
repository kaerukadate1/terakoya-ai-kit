# AIアシスタント設計ツール ビルドプロンプト

寺子屋AI 第4回 v0.2.0。「自分だけのAIアシスタントを作ろう」。事業・プロジェクトの準備を必須にせず、汎用アシスタントの作成・保管を主役にする。

## 読む順番

同じGit refのcharacter-studio/README.md、手順.md、スキル.md、skills/persona-design/SKILL.md、skills/work-execution/SKILL.mdを読む。次にlp/skills/terakoya-web-design/SKILL.mdとそのreferences/work-sites-guidance.md、character-studio/app/のindex.html・styles.css・core.js・app.js・assets一式、tests/core.test.cjsを読む。通常ページを読めなければ同じrefのraw URLを試せる。取得できなければ報告して止め、古い仕様を混ぜない。

## 固定の仕様

表示名「AIアシスタント設計ツール」。担当→話し方・判断方針→見た目→パッケージ→一覧の5段階。静的HTML/JSを基本にし、APIキーや新規有料サービスを要求しない。

- 5カテゴリー各6担当、計30担当。話し方10、判断方針8、任せる範囲3、相談タイミング3。任意カスタム役割・自由な性格入力は追加しない。名前は自由入力。
- 見た目は表現5・モチーフ5・雰囲気6・装い6。各64色と自由色。見た目と能力は切り離す。
- 21,600の仕事設定、3,686,400の見た目設定、合計79,626,240,000は設定の組み合わせ数。能力・実証済み品質・ユニーク画像の数とは表現しない。
- プロフィール・任意の画像・Markdown設定ファイル・短い呼び出し文をひとまとめに保存する。Markdownと呼び出し文は同じ設定から生成し、ファイル名を一致させる。
- 事業情報、既存プロジェクト、初仕事は保存の必須条件にしない。一覧は初期状態で空。
- Markdownを添付する単発Work、プロジェクト資料へ追加する使い方の2種類の呼び出し文。チャット内だけに役割を適用し、全プロジェクトの指示を上書きしない。
- 実行機能や権限、独立エージェント登録、常駐、定期実行、自動記憶同期は追加しない。読めないファイルを読んだと言わない。
- 画像制作の依頼を確認後、依頼文付きでChatGPTを開き、画像生成後に利用者がファイルを追加する。自動実行・自動返送・自動保存を偽装しない。
- 画像変更前の選択と現在の選択が異なれば、その状態を表示する。生成済み画像を選択変更だけで勝手に差し替えない。
- 一覧の再編集・複製・検索・カテゴリー絞り込み・削除確認・JSONバックアップと追加読み込みを備える。
- ブラウザ内保存。保存失敗は未保存として通知。壊れた既存保存を上書きしない。v1は原本と自由記述を保管し、旧事業情報を汎用Markdownへ混ぜない。
- すべての設定に、公開・送信・課金・契約・認証・権限・削除・機密送信の承認境界を残す。

## 検証

構文、単体テスト、PC/モバイル表示、空状態、保存・再読込、各選択肢、64色、画像取り込み、実ダウンロード、実コピー、複製、検索、削除キャンセル、バックアップ追加を確認する。ユーザーの既存データを使って削除テストをしない。Sitesが利用できれば公式手順で作成・表示。既存Siteは同じID・公開範囲とデータを保持する。
