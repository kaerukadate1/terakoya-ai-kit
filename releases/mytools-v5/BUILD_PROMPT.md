# 寺子屋AI マイサイト v5 | ビルドプロンプト

この文書は、短い「スタータープロンプト」から読み込む本体の制作指示です。参加者が自分のChatGPT Work / Sitesなどで作成・更新する個人用サイトです。「本人専用」は用途を指し、サイト内に独自のログインや厳格な所有者判定を追加する指示ではありません。作成者が開けないサイトを完成扱いにしないでください。

## 目的

本人の仕事で使うものを一か所に集めた「寺子屋AI マイサイト」を作ります。従来のWebツールURLに加えて、ローカルのファイル・バッチ、スキル、プロンプト、その他の参照情報を登録し、種類で絞り込めるようにします。ブラウザはローカルのバッチやスキルを直接実行・インストールできません。対象の場所や本文を保存・コピーするだけです。

## 読む順番と固定版

1. この文書と同じ `releases/mytools-v5/` の `README.md`、`index.html`、`styles.css`、`app.js`、`assets/terakoya-logo.jpg` と、`plugins/terakoya-ai-creative/skills/terakoya-web-design/SKILL.md` を実際に取得してください。ChatGPT Work / Sitesで制作する場合は同スキルの `references/work-sites-guidance.md` も読みます。取得できなければ読んだふりをせず、どのファイルが読めなかったか報告してください。
2. 同フォルダの画面と登録動作を基準にします。デザインスキルは読みやすさ・操作・検証に適用し、採用済みのHTML/CSS/JSを一から再設計しません。アクセスと保存は利用環境の標準機能に合わせ、独自の認証ゲートを追加しません。見た目はv4のロゴ、紺と金、明朝見出しを引き継ぎます。固定ファイル内の旧データ取込欄は新規サイトでは空のままにします。
3. 次回講座は公式サイトの `https://terakoya-ai.vercel.app/api/next-workshop` から取得します。取得する公開項目はタイトル・内容・開催日時です。運営が反映した公開データだけを表示し、未公開・取得失敗なら古い講座情報を代わりに出しません。任意URLを代理取得するAPIは作りません。旧 `announcements.json` のデモは表示しません。

参照元リポジトリ: `https://github.com/kaerukadate1/terakoya-ai-kit`。制作時はスタータープロンプトが指す同じコミット・タグ・ブランチのファイルをそろえて使用してください。GitHub上のファイルを取得できない場合、ファイルの中身を推測で再現しないでください。

## 登録仕様

登録項目は `id / type / target / name / description / memo / guideUrl / icon`。`type` は次の5種類です。

| 種類 | `target`に保存するもの | 一覧での主操作 |
| --- | --- | --- |
| `web` | `http`/`https` のURL | 別タブで開く |
| `local` | 手元のファイル・フォルダ・バッチの場所 | 場所をコピー。実行しない |
| `skill` | GitHub等のURL、または手元のスキルの場所 | 安全なWeb URLだけ開く。それ以外はコピー。インストールしない |
| `prompt` | プロンプト本文 | 本文をコピー。自動実行しない |
| `other` | その他の参照先や識別子 | 内容をコピー。自動実行しない |

- 種類選択に応じて入力名と説明を変え、必須の名称と参照先/本文を検証します。Web URLと説明ページURLには `http`/`https` 以外を使わせません。保存済みデータも開く前に同じ検証をします。
- `skill` は登録と参照だけです。スキルの内容をサイト内で実行したり、GitHubのコードを自動でインストールしたりしません。
- `local` はパスのメモです。ブラウザで `.bat`、`.cmd`、`.ps1`、`file://` を直接起動する設計にしません。実行が必要なら利用者がローカル環境で確認して行います。
- 種類ごとの絞り込み、追加、編集、並べ替え、一覧からの解除、再読込後の保持が必要です。以下の一覧管理操作を省略して完成扱いにしません。
- 新規サイトでは道具・スキル・プロンプト・その他の登録一覧を空にします。事業プロフィール、個人ロゴ、サイト名も未入力から始めます。固定画面、過去のサイト、同じブラウザのv4/v5保存データ、制作担当者のデータ、サンプル登録を初期データとしてコピーしません。共通の次回講座告知と寺子屋AIの固定ロゴは個人の登録データではありません。
- 既存サイトの更新を本人が依頼した場合だけ、そのサイトの既存データを保持します。旧v4の `{url,name,...}` 登録は `type:web`、`target:url` に変換できますが、対象サイトと保存元が同じ本人のものだと確認した場合に限ります。移行前の保存データを復元可能にし、他人のデータを取り込みません。

## 道具一覧の管理操作

- Webツール、ファイル・バッチ、スキル、プロンプト、その他の各登録に、見つけやすい「一覧から外す」と順番変更の操作を表示します。「×」だけで解除を表さず、PC・スマホのどちらでも操作を見つけられるようにします。
- 「一覧から外す」は確認を挟み、このマイサイトの登録情報だけを解除します。リンク先のサイト、元ファイル、バッチ、スキル本体、プロンプト原本は削除しません。解除後に再読込しても一覧へ戻らないことを確認します。
- 上下の順番変更は保存・再読込後も維持します。種類で絞り込んだ場合も、その画面で見えている項目同士を入れ替え、隠れている種類の登録は消しません。先頭・末尾で動けない方向は無効にします。
- 既存サイトを更新する場合も、登録済みの項目を失わずにこれらの操作を追加します。見た目だけのボタン、保存されない並べ替え、元データを削除する解除は不可です。

## 新規作成と既存更新の分岐

- 新規作成: サイトごとに新しい一意のIDを発行し、`index.html` の `terakoya-site-id` に設定します。`terakoya-import-storage-key` は空欄のままにします。サーバー保存を使う場合も新しいサイト専用の空の保存領域を作り、旧サイトの登録データを複製しません。同じブラウザに過去のサイトのデータがあっても、最初の道具一覧は0件です。
- 既存サイトの更新: 同じ `terakoya-site-id` と保存先を維持します。旧版からの移行が必要な場合だけ、本人の既存データと確認した保存キーを `terakoya-import-storage-key` に設定し、移行後も元データを消しません。更新を新規作成と取り違えて既存データを空にしません。
- 作り直しを新規サイトとして依頼された場合も新しいIDを使い、空の状態から開始します。過去のサイトや保存データは削除しません。新規か更新か判断できないときは、既存データの上書き・削除・自動取込を行わず、どちらか確認します。

## アクセスと保存

- 作成者がサイトを作ったアカウントの通常の利用手順で、そのまま開いて編集できることを優先します。サイト内に別のログイン画面、パスワード、メールアドレス照合、固定の所有者ID、許可リスト、招待承認フローを作らないでください。独自判定で作成者まで締め出してはいけません。
- 公開範囲はWork / Sitesなどの標準の共有設定で、利用できる範囲のうち適切なものを選びます。サイトが非公開かどうかを推測で断言しません。別のアカウントからの閲覧を制限できない環境では、その制限を実装済みと称さず、公開範囲を利用者に明示します。
- 保存は環境が提供する利用者別の永続保存を優先します。使えない場合は既存の `localStorage` 版で作成者が使える状態にし、同じブラウザ内の保存であること、別端末との同期がないことを明記します。独自認証を保存機能の前提にしません。サーバー保存を実装する場合だけ、環境が提供する実際のログイン情報で利用者ごとのデータを分け、全員で同じ保存領域を共有しません。
- 既存サイトを更新する場合は、作成者が管理できる対象を確認し、既存データを失わない更新手順を選びます。別人のサイトや保存領域を上書きしません。
- プロンプト本文、ローカルパス、個人の事業情報をGitHub、共通告知、公開ページへ書き込みません。登録したURLへサイトから勝手に通信したり、ローカルのコマンドを実行したりしません。
- 保存対象は、事業プロフィール、登録項目と順序、アイコン、個人ロゴ、サイト名、テーマと配色です。保存失敗時は成功表示をしません。

## 完成確認

デスクトップ幅と390px幅で表示し、以下を実際に確認してください。

1. 新規サイトは、同じブラウザに旧v4/v5の保存データがあっても道具一覧が0件。既存サイトの更新では、本人の登録データが残り、旧v4のURLも移行した場合はWebとして開ける。
2. 5種類すべてを登録・編集・絞り込みでき、再読込後も残る。
3. WebとURL型スキルだけが安全な外部リンクになり、バッチやプロンプトはコピーのみ。`javascript:` 等は開かない。
4. 各種類で「一覧から外す」が表示され、確認後は登録だけが消えて再読込でも戻らない。全件・絞り込み中の上下移動が保存され、移動できない方向は無効。元ファイル・元ツール、プロフィール、ロゴ、配色は保持される。
5. 作成したアカウントでサイトを開き、登録・保存・再読込・編集ができる。独自ログインや所有者判定で締め出されない。共有範囲と保存方式を実際に確認する。告知のデモ・期限切れは表示されない。

確認できない項目は `未確認` と明記します。サイトURL、使用した版/参照コミット、新規・更新の区別と初期登録件数、作成者による開閉・保存の確認結果、実際の共有範囲と保存方式、既存データ移行結果、未完了点を短く返してください。ZIPやコードだけを渡して完成としないでください。参加者へGit操作、APIキー、手動デプロイを求めないでください。
