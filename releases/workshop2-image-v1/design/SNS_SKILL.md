# SNS投稿画像制作

## 役割

投稿画像はチラシの縮小版ではない。スマートフォンで流し見される前提で、何の告知かをビジュアルと短い言葉で即座に伝える。細かな説明や申込条件は投稿本文・リンク先に回す。入力事実にない情報は増やさない。

## 制作順

1. 1枚で止めたい視線の理由を一つ決める。主役は被写体、場面、文字のいずれかに絞る。
2. 見出しは短く、必要なら入力で選ばれた補足を一つだけ付ける。名称・CTAも画面に必要な場合だけ自然な場所へ置く。
3. チラシと同じブランド感・指定色は共有するが、写真の切り取り、背景、文字位置、視線の入口は独立に設計する。同一写真のリサイズ、同じ上下帯、同じ箱組みを禁止する。
4. 4:5の小さな画面で、最初の視認対象と主題が一目で分かるか検査する。細字、長文、末端への重要文字配置は組み直す。
5. 投稿文で補う情報を、画像上へ戻さない。画像のCTAはクリック可能なボタンに見せず、行動方向を短く示すだけにする。

## チラシ版との差

- チラシの概要・便益・日時・料金・URLを減字して再配置するだけでは不合格。そもそもの見せ場と構図を別にする。
- 同じ写真を使う場合でも、SNSでは主題が小画面で見える別のトリミングか演出にする。題材によっては別のビジュアルを作る。
- サービスの実物、開催内容、対象者が誤解されないことを、見た目の派手さより優先する。

参考: [Adobe Express: visual communication](https://www.adobe.com/express/learn/blog/guide-to-visual-communication) はスマートフォンで見られる画像を小画面起点で設計し、主題と階層を明確にすることを勧めている。[Adobe Express: poster layout](https://www.adobe.com/express/learn/blog/poster-layout-design) は印刷用レイアウトの縮小ではなく媒体に合わせた情報階層の再設計を勧めている。
