# 寺子屋AI チラシ・SNS告知画像制作ツール / デザインルール

## 共通

- デザイン案は3つ。案ごとに9種類からレイアウトを選び、背景色とアクセント色を自由に指定する。同一案のチラシとSNSでは視覚的な系統を揃えるが、SNSをチラシの縮小版にしない。
- 04のCanvasは構成下見であり完成画像ではない。05の生成では案ごとに合う画像表現・質感・余白を作る。ビジュアルは画像生成を使い、日本語・URL・数字は正確なテキスト描画で合成して文字化けや誤記を避ける。
- ツールのライト/ダーク/システムとメイン/サブカラーは操作画面の設定であり、完成画像の色に混ぜない。
- 入力された事実だけを使う。日付、料金、受講者数、効果、実績、人物を捏造しない。提供写真は本人が会話に添付した場合だけ元写真として使う。

## 9種類の構図

1. エディトリアル: 余白と整列で情報を読む。
2. フォト: 実写真または生成ビジュアルを主役にする。
3. タイポグラフィ: 大きな言葉と色面で伝える。
4. スプリット: 左右の異なる役割を対比する。
5. グリッド: 見出し、画像、具体情報を升目で整理する。
6. ポスター: 中央の主題に視線を集める。
7. ミニマル: 一文と大きな余白を活かす。
8. マガジン: 誌面の流れで写真から本文へ導く。
9. フレーム: 囲み構図で情報を印象づける。

## 媒体

| 媒体 | 目的 | 出力 |
|---|---|---|
| チラシ | 1枚で内容と次の行動を判断できるよう、確定済みの説明・メリット・日時・料金・URLを必要に応じて掲載 | A4 PNG 2480 x 3508 |
| SNS | 小画面で何の告知かをひと目で示し、情報を絞る | 4:5 PNG 1080 x 1350 |

- 長い語は折り返し、見出しやボタンの中で切れないようにする。顔や商品がある場合は不自然に切らない。
- SNS版は補足を最大1つに絞る。チラシの情報を詰め込まない。
- 完成画像の修正は既存画像を壊さず、新版として出す。表示一覧から外す操作と画像自体の削除を混同しない。
