# 寺子屋AI チラシ・SNS告知画像制作ツール / デザインスキル

## 共通

- デザイン案は3つ。案ごとに9種類の雰囲気から選び、背景色とアクセント色を自由に指定する。同一案のチラシとSNSでは視覚的な系統を揃えるが、SNSをチラシの縮小版にしない。
- デザイン選択は雰囲気と色の指定であり、完成構図の指定ではない。固定レイアウトの下見を経由せず、各媒体のスキルを読んで構図を決める。
- `FLYER_SKILL.md` と `SNS_SKILL.md` を必ず併用する。同じ案の2媒体にはブランドのつながりを残しながら、情報の役割、写真の扱い、文字組みを別にする。
- ビジュアルは画像生成を使い、日本語・URL・数字は正確なテキスト描画で合成して文字化けや誤記を避ける。文字まで画像生成に任せない。
- ツールのライト/ダーク/システムとメイン/サブカラーは操作画面の設定であり、完成画像の色に混ぜない。
- 入力された事実だけを使う。日付、料金、受講者数、効果、実績、人物を捏造しない。提供写真は本人が会話に添付した場合だけ元写真として使う。

## 仕上がりの基準

- まず名称、ひとこと、補足、行動先の優先順位を決める。SNSは主役の一文を短く見せ、説明を詰め込まない。チラシは読み順を明確にして必要な情報を補う。
- 日本語は意味のまとまりで改行する。助詞だけが行頭・行末に孤立しないようにし、最後の行が極端に短ければ改行位置か文字サイズを調整する。見出しを大きくすること自体を目的にしない。
- 文字は収まるまで実寸で測る。箱からのはみ出し、切れ、重なり、狭すぎる行間を認めない。小さくしすぎるより、情報を削る・場所を変える・構図を組み直す。
- 写真は主役か背景か役割を決める。写真と文字が意味なく半分ずつ分離したり、片側に説明不能な空白が残ったりしない。被写体の焦点、切り抜き、文字との距離を確認する。
- CTAは静止画像では必ずしもボタンにしない。目的に応じて短いテキスト、矢印、控えめなラベルなどを選び、汎用的な全幅の色帯を惰性で使わない。押せる機能がない画像をUIボタンのように誤認させない。
- 枠線、色面、角丸、影は情報の区切りに必要な時だけ使う。同じ太さの箱を並べてテンプレート感を出さない。フォントは題材に合わせて選び、全画像で同じ文字組みにしない。
- 指定色のコントラストを確認し、写真上の文字にも十分な可読性を確保する。写真の良さを隠すベタ塗りや不自然なトリミングは避ける。

## 納品前の画像チェック

各PNGを完成サイズとスマートフォン相当の縮小表示の両方で見て、次の全項目を確認する。1項目でも不合格なら再配置・再合成してから保存する。

1. 最初に視線が行く主役が明確で、名称、見出し、補足、CTAの読む順が自然。
2. 見出しの改行が意味で切れ、極端な短行・文字切れ・重なり・余白の偏りがない。
3. 写真と文字が一つの構図として成立し、被写体が適切に見える。
4. CTAが画像全体のトーンに合い、必要以上に大きなボタンや帯になっていない。
5. 表記、数字、URL、日時が入力原文と一致し、未入力の事実が増えていない。

完成報告では、選んだ文字組みとCTAの処理、上記チェックで直した点を短く述べる。画像を実際に見られなかった場合は合格と宣言しない。

## 9種類のデザイン方向

`settings.designs[].layout` は以下の順番に対応する。構図の下見より選択した雰囲気を優先し、題材と媒体に合わせて最終の写真・文字組みを調整する。

1. 洗練: 余白と整列を使い、すっきり見せる。
2. ナチュラル: 写真を大きく使い、柔らかく見せる。
3. インパクト: 言葉と色を主役に、力強く伝える。
4. 親しみ: 写真と文章を並べ、身近に感じさせる。
5. 信頼感: 見出しと情報を整理し、安心して読めるようにする。
6. 華やか: 主役を中央に置き、明るい印象を作る。
7. シンプル: 一つの言葉と余白で静かに伝える。
8. 上品: 誌面のような落ち着いた流れを作る。
9. クール: 輪郭を引き締め、端正な印象にする。

## 媒体

| 媒体 | 目的 | 出力 |
|---|---|---|
| チラシ | 1枚で内容と次の行動を判断できるよう、確定済みの説明・メリット・日時・料金・URLを必要に応じて掲載。`FLYER_SKILL.md` を適用 | A4 PNG 2480 x 3508 |
| SNS投稿画像 | 小画面で主題をひと目で示す。チラシとは別構図で `SNS_SKILL.md` を適用 | 4:5 PNG 1080 x 1350 |

- 長い語は折り返し、見出しやボタンの中で切れないようにする。顔や商品がある場合は不自然に切らない。
- SNS版は補足を最大1つに絞る。チラシの情報を詰め込まない。
- 完成画像の修正は既存画像を壊さず、新版として出す。表示一覧から外す操作と画像自体の削除を混同しない。
