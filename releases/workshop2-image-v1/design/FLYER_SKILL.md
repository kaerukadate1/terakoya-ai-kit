# A4チラシ制作

## 役割

チラシはSNS画像の縦長版ではない。数秒で主題が分かり、興味を持った人が手元で詳細を読み、参加・問い合わせの判断までできる1枚にする。必須情報が入力されていなければ創作せず、確定情報だけで成立させる。

## 制作順

1. 読む相手、1枚で答えるべき問い、最も大事な一文を決める。
2. 見出し、概要、便益、確定済みの日時・場所・料金、行動先を重要度で選別する。入力済みでも掲載オフの項目は載せない。
3. まず視線の流れを、主役→内容→判断材料→行動先の順に設計する。文字量が多いときは階層化し、同じ大きさの箱を並べない。
4. 写真は主役の理解を助ける位置に置く。画像とテキストを機械的に半分ずつ分割しない。
5. 印刷サイズと手元での読みやすさを検査する。日時、料金、URLの小文字化、端への寄せすぎ、コントラスト不足、読み順の迷いを直す。

## SNS版との差

- A4の余白は情報を整理するために使い、空白を埋めるために飾らない。
- 概要と複数の便益は、判断に必要なら掲載してよい。SNS版に同じ本文を転用しない。
- チラシのCTAは印刷物から次に取る行動を明示する。押せない画像の中にWebの全幅ボタンを描かない。
