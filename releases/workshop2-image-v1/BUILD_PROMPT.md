# 寺子屋AI チラシ・SNS告知画像制作ツール / ビルドプロンプト v1

## 目的

受講生本人だけが開けるWorkのサイトに「寺子屋AI チラシ・SNS告知画像制作ツール」を作る。LP制作ツールに近い5段階の画面で、共通情報の入力、媒体ごとの構成、3案のデザイン設定、6枚の比較、完成画像の保存まで進む。

## 固定ファイル

この文書と同じリリースの次のファイルを実際に読む。GitHubの別ブランチや別バージョンを混ぜない。

- `index.html`: 制作画面
- `styles.css`: 画面スタイル
- `app.js`: 入力、3案表示、PNG書き出し
- `consult.js`: ChatGPTへの相談文、回答JSONの検証と入力欄への反映
- `state.js`: 構成とデザイン設定、媒体ごとの表示内容
- `library.js`: 完成画像のブラウザ内保存と再取得
- `design/SKILL.md`: デザイン・媒体変換の制作ルール

基点URL: `https://raw.githubusercontent.com/kaerukadate1/terakoya-ai-kit/main/releases/workshop2-image-v1/`

## 作るもの

1. 上記固定ファイルをベースに、この実行専用の本人限定サイトを完成させる。必要な調整は実行環境の配置・保存方法に限り、入力項目、5段階の導線、3デザイン、媒体の切り分け、画像の解像度、完成画像一覧を保持する。既存のサイトや入力データは上書きしない。
2. 「内容を入れる → 構成を決める → デザインを選ぶ → 画像を比べる → 完成画像」の順で進む。チラシでは説明・メリット・確定済みの開催情報・申込先の掲載を選べる。SNSでは補足情報を1つだけ選び、画像の文字量を抑える。
3. 各案のレイアウトと配色を選べるようにし、共通入力からそれぞれチラシ版とSNS版を展開する。
4. 写真は任意。未指定なら文字と色面のデザインを使い、存在しない人物、実績、日時、価格、特典を捏造しない。入力が空の情報は公開用PNGから省く。
5. A4のPNGは2480 x 3508 px、SNSのPNGは1080 x 1350 px。長い文章でレイアウトが崩れないよう調整する。
6. 「完成画像に保存」は選んだ画像のPNGと小さなプレビュー、入力・設定の控えをブラウザのIndexedDBに保存する。「完成画像」で一覧表示、PNG再取得、設定の再読込ができる。端末・ブラウザ・サイトURLをまたぐ同期やクラウド保存とは説明しない。画像の写真素材は設定から再読込できないため、編集時は再選択する。
7. 個人情報・顧客情報を事前入力やサンプルに含めない。写真はユーザーが明示的に指定したものだけ使う。無断の外部送信をしない。
8. 「ChatGPTに相談」はLP制作ツールと同じく、現在の入力を踏まえた依頼文でChatGPTを開き、返ってきたJSONまたは入力案リンクを本人が確認して反映する。参照できる範囲の過去チャット・プロジェクト資料・メモリだけを使い、サイト自身が履歴を直接取得したように装わない。未確定情報は作らず、既入力欄は本人が上書きを選んだ時以外は維持する。

## 実装時の注意

- 固定ファイルを「参考にして似た画面を作る」のではなく、実際に取り込んで動かす。リンクだけを掲載して完成扱いにしない。
- `index.html` を開いて5段階の移動、構成・配色の変更、3案 x 2媒体の表示、A4とSNSのPNG保存、完成画像への保存・再取得、スマートフォン表示を確認する。
- 相談ボタンからChatGPTへの依頼文、回答JSONの貼り付け、未入力欄への反映、既入力欄の保護を確認する。相談の回答には個人情報や未確認の事実を混ぜない。
- Workに保存して本人限定で発行できる場合は、実際に発行し、本人が開けるURLを返す。一般公開やグループ共有、追加課金を伴う設定はしない。発行できない場合は理由と取得・保存できた範囲を明記し、公開済みと装わない。
- 固定HTML版のテキスト入力と構成・デザイン設定は `localStorage`、保存した完成画像は `IndexedDB` に残る。どちらも同じブラウザ内の保存で、クラウド保存や自動共有ではない。写真素材の元ファイルは再読込後に保持されない。
- ファイル取得、公開、保存、PNG書き出しのどこまで実際に確認したかを分けて報告する。

## 完了条件

- 受講生が同じ入力から3デザインを比較できる。
- 各デザインでチラシとSNSの表現・情報量が実際に異なる。
- 選んだ6種をそれぞれPNGで保存できる。
- 未入力情報が勝手に確定値として表示されない。
- ChatGPTへの相談で作った入力案を本人が確認して取り込み、既入力欄を保護できる。
- 掲載内容と3案のデザイン設定がプレビューへ反映され、保存した完成画像を一覧からPNGとして再取得できる。
- 開けるURLまたは保存先と、未確認点を報告する。
