# 寺子屋AI チラシ・SNS告知画像制作ツール / ビルドプロンプト v1

## 目的

受講生本人だけが開けるWorkのサイトに「寺子屋AI チラシ・SNS告知画像制作ツール」を作る。共通の入力情報から3つのデザインを作り、各デザインをチラシA4とSNS投稿4:5へ展開する。完成形は3案 x 2媒体の6枚を比較し、選んだ画像をPNGで保存できる状態。

## 固定ファイル

この文書と同じリリースの次のファイルを実際に読む。GitHubの別ブランチや別バージョンを混ぜない。

- `index.html`: 制作画面
- `styles.css`: 画面スタイル
- `app.js`: 入力、3案表示、PNG書き出し
- `design/SKILL.md`: デザイン・媒体変換の制作ルール

基点URL: `https://raw.githubusercontent.com/kaerukadate1/terakoya-ai-kit/main/releases/workshop2-image-v1/`

## 作るもの

1. 上記固定ファイルをベースに、この実行専用の本人限定サイトを完成させる。必要な調整は実行環境の配置・保存方法に限り、入力項目、共通3デザイン、媒体の切り分け、画像の解像度を保持する。既存のサイトや入力データは上書きしない。
2. 共通入力を1回だけ受け取り、デザイン1〜3をそれぞれチラシ版とSNS版に展開する。チラシは内容・メリット・日時・料金・申込先など確定情報を詳しく載せ、SNSは主見出しと視覚的訴求を優先して文字量を減らす。
3. 写真は任意。未指定なら文字と色面のデザインを使い、存在しない人物、実績、日時、価格、特典を捏造しない。入力が空の情報は公開用PNGから省く。
4. A4のPNGは2480 x 3508 px、SNSのPNGは1080 x 1350 px。長い文章でレイアウトが崩れないよう調整する。
5. 個人情報・顧客情報を事前入力やサンプルに含めない。写真はユーザーが明示的に指定したものだけ使う。無断の外部送信をしない。

## 実装時の注意

- 固定ファイルを「参考にして似た画面を作る」のではなく、実際に取り込んで動かす。リンクだけを掲載して完成扱いにしない。
- `index.html` を開いて入力、3案 x 2媒体の表示、A4とSNSのPNG保存、スマートフォン表示を確認する。
- Workに保存して本人限定で発行できる場合は、実際に発行し、本人が開けるURLを返す。一般公開やグループ共有、追加課金を伴う設定はしない。発行できない場合は理由と取得・保存できた範囲を明記し、公開済みと装わない。
- 固定HTML版のテキスト入力は端末内の `localStorage` に保存するが、写真は再読込後に保持されない。これをクラウド保存や自動共有と説明しない。
- ファイル取得、公開、保存、PNG書き出しのどこまで実際に確認したかを分けて報告する。

## 完了条件

- 受講生が同じ入力から3デザインを比較できる。
- 各デザインでチラシとSNSの表現・情報量が実際に異なる。
- 選んだ6種をそれぞれPNGで保存できる。
- 未入力情報が勝手に確定値として表示されない。
- 開けるURLまたは保存先と、未確認点を報告する。
