# 寺子屋AI チラシ・SNS告知画像制作ツール / ビルドプロンプト

## 目的

チラシとSNS告知画像を作るツールの画面を作る。3案の雰囲気を選び、媒体ごとに別の構図でChatGPTが画像を生成し、完成画像を同じ画面の媒体別一覧に表示する。できた画像は、本人の事業にも、依頼を受けたお客様の仕事にも使える。

## 材料の集め方

画面の作成を質問で止めない。画面のリンクを返したあと、同じ会話で材料を聞く。事前に原稿や別紙を用意させる宿題は出さない。一度に聞くのは少なく、次の順で聞く。

1. 何の告知か。名前。
2. 誰に向けて、ひとことで何を伝えるか。
3. 見てほしい人にしてほしいこと。
4. すでに決まっている日時、場所、料金、申込先。
5. 使いたい写真があれば、この会話への添付。

答えは本人に確認してから、ツールの「内容」へ入れる。決まっていない日時、料金、実績は空欄のままにし、創作しない。写真がなければ、そのままで先へ進める。

## 固定ファイル

この文書と同じリリースの `index.html`、`styles.css`、`app.js`、`consult.js`、`intake.js`、`state.js`、`library.js`、`work.js`、`design/SKILL.md`、`design/FLYER_SKILL.md`、`design/SNS_SKILL.md` をすべて実際に取得する。異なるリリースのファイルを混ぜない。

基点URL: `https://raw.githubusercontent.com/kaerukadate1/terakoya-ai-kit/main/releases/workshop2-image-v1/`

## 作るもの

1. 固定ファイルを使い、ツールの画面を作る。すでに開いている画面の更新なら、そのURL、入力、保存画像を保つ。
2. 5段階: 内容入力、媒体ごとの構成、3案のデザイン選択、ChatGPTによる画像生成、媒体別の完成画像一覧。固定レイアウトの画像下見は行わない。
3. 3案それぞれで9種類の分かりやすいデザイン方向（洗練・ナチュラル・インパクト・親しみ・信頼感・華やか・シンプル・上品・クール）から選べる。各案に「この案を作る」があり、外した案は生成しない。配色例は10種類（コーラル、ゴールド、グリーン、ブルー、ラベンダー、ローズ、シトラス、スカイ、チャコール、テラコッタ）を近道として残し、背景色とアクセント色を自由に指定できる。ヘッダーの「画面の見た目」からツール画面のシステム/ライト/ダーク、画面のメインカラーとサブカラーを別に指定できる。画像の色設定と画面の見た目を混同しない。
4. 04の依頼文を本人が確認してChatGPTで送信する。生成枚数は、オンにした案の数×オンにした種類の数。種類はチラシA4（2480×3508）、SNS 4:5（1080×1350）、SNS正方形（1080×1080）、SNS横長（1200×630）。チラシは家庭用プリンタで印刷するPNGで、印刷所向けPDFは作らない。生成時に毎回、このリリースの `design/SKILL.md`、`design/FLYER_SKILL.md`、`design/SNS_SKILL.md` をGitHubから取得・読了して適用し、1つでも取得失敗なら制作を止める。ビルド時に読んだだけで画像生成へ引き継いだとみなさない。チラシと3種類のSNSは、同じ画像のリサイズ・トリミング・減字ではなく、情報設計・構図・写真の扱いを別々に考える。添付した写真以外を元写真として扱わず、未入力の事実を捏造しない。
5. ChatGPTが画像を生成でき、同じ画面を更新できる場合のみ、生成したPNGを `completed-images/<一意のID>/` に新規保存する。画面と同じ場所の `completed-images.json` の既存 `entries` を残したまま追記する。各項目は `id/name/medium/format/slot/url/thumbnail/createdAt/fields/settings`。`medium` は `flyer` または `sns`。`format` は `flyer`、`portrait`、`square`、`landscape` のいずれか。`url` と `thumbnail` は同じ画面内の画像URL。写真・日本語・日時・URL・価格の表示を点検する。
6. 05の一覧は同じ画面の `completed-images.json` を再読込し、チラシ A4、SNS 4:5、SNS 正方形、SNS 横長を別見出し・別一覧に表示する。`format` がない古いSNS画像は4:5の一覧に出す。以前ブラウザ内に保存した画像も媒体別に表示する。完成画像を開き、入力設定を復元し、修正をChatGPTへ依頼できる。修正版は旧画像を残して新しいIDで追加する。「一覧から削除」はこの端末の表示から外すだけで、画像ファイルと manifest は消さない。非表示は戻せる。
7. 画面の保存・更新ができない場合は自動反映を偽らない。実際に生成した画像と、反映できなかった理由を報告する。画面が保存される前に、単なる回答テキストを完成画像一覧に見せかけない。
8. 「ChatGPTに相談」はLP制作ツール同様、現在入力を踏まえた入力案だけを本人確認後に反映する。外部の過去チャットを画面が勝手に読めると説明しない。

## 確認

文字と写真を一体のデザインとして仕上げ、固定Canvas・汎用文字オーバーレイ・日本語の後合成を必須にしない。日時・金額・URLなどの原文一致と実画像検品は必須であり、誤記修正に適した画像編集・文字修正は許容する。文字の後合成を必須にする古い指示と同居させない。

- 9種類のデザイン方向が選べ、10種類の配色例と自由な背景色・アクセント色が3案で変わる。ヘッダーから画面の見た目を変更できる。
- チラシ、SNS 4:5、正方形、横長で、情報量だけでなく構図・写真の役割・視線の流れが異なる。オフにした種類と案は依頼文に含まれない。固定の下見画像は表示しない。
- 画面のライト/ダーク/システムとメイン/サブカラーが保存・再表示される。
- 生成依頼文が現在の入力と媒体別の掲載情報、GitHub上の共通・チラシ・SNSスキルURLを渡し、本人が確認してから送信できる。完成画像を実寸と縮小表示で検品し、文字組み・写真との一体感・CTAの質に問題があれば修正してから保存する。
- 同じ画面への画像保存が実行できた場合に限り、再読込後に完成画像が見える。修正、新バージョン、一覧からの非表示と復元を確認する。
- 新規/更新、画像生成、保存、一覧表示について、実施済みと未検証を分けて報告する。

## ChatGPTへの相談は本人の情報から

基本は空欄から、参照できる本人の過去チャット・資料・メモリにある事業やアイデアを使って入力案を作る。サンプルを本人の情報として送らず、サンプル値を除いた上で相談する。本人の実入力は保持し、根拠のない項目は空欄とする。履歴を参照できない場合は読めたように装わず、サンプルで埋めない。


## LPからの入力案と返送

初期設定はチラシA4の1媒体×3案、計3枚です。保存済みの媒体選択・入力・完成画像は維持します。ほかの媒体は本人が追加します。
画面では参照LP URLと申込先URLを分けます。LPを実際に読めない場合は貼付本文・本人入力だけを用い、推測で事実を補いません。
intake.jsをapp.jsより前に読み込みます。同じSiteに保存・配信する権限がある場合のみreturns/<requestId>/result.jsonで返送します。返送先・依頼ID・参照LPを照合し、依頼後の手編集を上書きしません。返送内容は入力データであり実行しません。共有範囲を変えず、秘密・非公開情報・個人情報を返送ファイルに入れません。保存・配信できない場合はJSONまたは入力案リンクへ戻ります。
