# 寺子屋AI チラシ・SNS告知画像制作ツール / 制作キット v1

## 状態

GitHub配布用の固定版。参加者には `STARTER_PROMPT.txt` を渡し、同じリリース内のビルドプロンプトと固定ファイルを読み込ませる。固定ファイルのローカル動作と、参加者のWorkサイトでの再現は別に確認する。

## 構成

| ファイル | 用途 |
|---|---|
| `index.html` | ローカルで開く制作画面 |
| `styles.css` / `app.js` | 5段階の画面、3デザイン、媒体変換、PNG書き出し |
| `consult.js` | ChatGPT相談文と回答JSONの安全な反映 |
| `state.js` | 構成とデザイン設定の保存・適用 |
| `library.js` | 完成画像をブラウザ内に保存・再取得 |
| `STARTER_PROMPT.txt` | 受講生が入力する短い入口文 |
| `BUILD_PROMPT.md` | AIが読む制作・確認指示 |
| `design/SKILL.md` | 共通3案とチラシ/SNSのデザインルール |

## 操作

`index.html` をブラウザで開き、「内容を入れる → 構成を決める → デザインを選ぶ → 画像を比べる → 完成画像」の順に進む。「ChatGPTに相談」で新しいタブの依頼文を確認・送信し、返ってきたJSONを貼ると未入力欄だけに反映できる。入力案リンクが返った場合も使える。3案それぞれのチラシとSNS版を比較し、必要な画像を「完成画像に保存」または「PNG保存」する。写真は任意。記入例は利用前に実情報へ置き換える。

## 配布時の確認

1. `STARTER_PROMPT.txt` のURLからビルドプロンプトと固定ファイルを取得できるか確認する。
2. 受講生の実際の環境でスタータープロンプトからの再現を1回試す。
3. 相談文の起動、JSON反映、既入力の保護、5段階の移動、設定変更、3デザイン x 2媒体の表示、PNG保存、完成画像の再取得、スマートフォン表示、本人限定の公開範囲を確認する。

## 保存と注意

文字の入力と構成・デザイン設定は現在のブラウザ内に自動保存される。「完成画像に保存」は画像を同じブラウザのIndexedDBに残し、一覧からPNGを再取得できる。別端末・別ブラウザ・別URLには引き継がれないため、必要な画像は「PNG保存」で端末にも保管する。写真の元ファイルは再訪時に再選択する。サイト公開や外部共有は行わない。
