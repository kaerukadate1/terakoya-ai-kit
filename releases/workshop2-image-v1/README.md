# 寺子屋AI チラシ・SNS告知画像制作ツール / 制作キット

## 使い方

- 新規サイト: `STARTER_PROMPT.txt` をChatGPT Workに入力する。
- 既存の本人限定サイト: `UPDATE_EXISTING_SITE_PROMPT.md` を使う。新規スタータープロンプトは使わない。
- 制作は「内容 → 構成 → 3案のデザイン → 6枚の構成下見 → ChatGPTで画像生成 → 完成画像」。3案それぞれで9レイアウト、背景・アクセントの自由色を選べる。
- 画面右上の「外観設定」でシステム/ライト/ダークと、画面のメイン/サブカラーを変えられる。出力画像の色とは独立している。
- 04のPNGは構成下見。完成画像は05でChatGPTに依頼して実際に生成する。提供写真を使うなら会話へ再添付する。
- 05は毎回GitHubの `design/SKILL.md` を読んで適用する。生成したPNGは文字組み・余白・写真とCTAを実寸と縮小表示で確認し、問題があれば保存前に作り直す。

## 完成画像の保存

同じ本人限定WorkサイトをChatGPTが更新できる場合に限り、完成画像を `completed-images/<ID>/` に保存し、サイト直下の `completed-images.json` に追記する。06の一覧はこのJSONを読む。Work側がサイトを更新できなければ自動反映はできない。その場合は画像ファイルを受け取り、保存・掲載方法を別途決める。

「修正を依頼」は旧版を残して新しい画像を作る。「一覧から削除」はその端末の表示から外すだけで、画像ファイルやサイトを削除しない。表示は戻せる。旧版でブラウザに保存した画像も読み取り表示する。入力・外観・非表示設定はブラウザ保存で、端末間同期しない。

## 配布前の確認

`node --test tests/*.cjs` を通し、実際のWorkサイトでは9レイアウト、自由色、画面テーマ、生成依頼、完成画像の反映、修正・非表示・復元、スマートフォン表示を確認する。ソースのテストとWorkの画像生成・サイト更新は別の確認項目。画像が一覧へ自動反映したと報告する前に、Workサイトを再読込して実物を確認する。
