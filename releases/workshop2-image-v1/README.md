# 寺子屋AI チラシ・SNS告知画像制作ツール / 制作キット v1

## 状態

GitHub配布用の固定版。参加者には `STARTER_PROMPT.txt` を渡し、同じリリース内のビルドプロンプトと固定ファイルを読み込ませる。固定ファイルのローカル動作と、参加者のWorkサイトでの再現は別に確認する。

## 構成

| ファイル | 用途 |
|---|---|
| `index.html` | ローカルで開く制作画面 |
| `styles.css` / `app.js` | 画面、3デザイン、媒体変換、PNG書き出し |
| `STARTER_PROMPT.txt` | 受講生が入力する短い入口文 |
| `BUILD_PROMPT.md` | AIが読む制作・確認指示 |
| `design/SKILL.md` | 共通3案とチラシ/SNSのデザインルール |

## 操作

`index.html` をブラウザで開き、共通情報を入力する。3案それぞれのチラシとSNS版を比較し、必要な画像の「PNG保存」を押す。写真は任意。記入例は試用のための文案で、利用前に実情報へ置き換える。

## 配布時の確認

1. `STARTER_PROMPT.txt` のURLからビルドプロンプトと固定ファイルを取得できるか確認する。
2. 受講生の実際の環境でスタータープロンプトからの再現を1回試す。
3. 入力、3デザイン x 2媒体の表示、6種類のPNG保存、スマートフォン表示、本人限定の公開範囲を確認する。

## 保存と注意

文字の入力は現在のブラウザの端末内に自動保存される。画像ファイルは保存されないため、再訪時は再選択する。PNG保存は端末へのダウンロードであり、サイト公開や外部共有ではない。
