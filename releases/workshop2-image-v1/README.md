# 寺子屋AI チラシ・SNS告知画像制作ツール / 制作キット

参加者が開く説明は [flyer-sns](../../flyer-sns/README.md) です。このフォルダ名は、開始文が取得するパスなので変えていません。

できたチラシとSNS画像は、自分の事業にも、依頼を受けたお客様の仕事にも使えます。

## 出力

| 種類 | サイズ | 使い方 |
| --- | --- | --- |
| チラシ A4 | 2480×3508 | 家庭用プリンタで印刷するPNG |
| SNS 4:5 | 1080×1350 | 縦長のフィード投稿 |
| SNS 正方形 | 1080×1080 | 正方形のフィード投稿 |
| SNS 横長 | 1200×630 | タイムラインとリンクの共有 |

4種類は同じ画像の切り抜きにしません。画面で作る種類と作る案を選べます。全部オンだと3案×4種類で12枚です。チェックを外せば、チラシ1枚とSNS 1枚だけにもできます。

参加者向けの図解、開始文、当日の進行は [flyer-sns](../../flyer-sns/手順.md) にあります。開始文の原本は [開始文.txt](../../flyer-sns/開始文.txt) で、このフォルダの `STARTER_PROMPT.txt` と同じ文です。

## 使い方

- 新しい画面: `STARTER_PROMPT.txt` をChatGPT Workに入力する。Zoomのチャットに貼られた文は使わない。
- すでに開いている画面: `UPDATE_EXISTING_SITE_PROMPT.md` を使う。新規の開始文は使わない。
- 制作は「内容 → 媒体別構成 → 3案のデザイン → ChatGPTで画像生成 → 種類別の完成画像」。3案それぞれで9種類の雰囲気、背景・アクセントの自由色を選べる。作らない案は「この案を作る」を外す。
- 画面右上の「画面の見た目」でシステム/ライト/ダークと、画面のメイン/サブカラーを変えられる。出力画像の色とは独立している。
- 固定的な画像下見は省略する。04でChatGPTに依頼して実際に画像を生成する。提供写真を使うなら会話へ再添付する。
- 04は毎回GitHubの `design/SKILL.md`、`design/FLYER_SKILL.md`、`design/SNS_SKILL.md` を読んで適用する。チラシと3種類のSNSは同じ画像のサイズ違いにしない。生成したPNGは文字組み・余白・写真とCTAを実寸と縮小表示で確認し、問題があれば保存前に作り直す。

## 完成画像の保存

同じ画面をChatGPTが更新できる場合に限り、完成画像を `completed-images/<ID>/` に保存し、画面と同じ場所の `completed-images.json` に追記する。05の種類別一覧はこのJSONを読む。`format` のない古いSNS画像は4:5の一覧に残す。画面を更新できなければ自動反映はできない。その場合は画像ファイルを受け取り、保存・掲載方法を別途決める。

「修正を依頼」は旧版を残して新しい画像を作る。「一覧から削除」はその端末の表示から外すだけで、画像ファイルやサイトを削除しない。表示は戻せる。旧版でブラウザに保存した画像も読み取り表示する。入力・外観・非表示設定はブラウザ保存で、端末間同期しない。

## 確認

`node --test tests/*.cjs` と `node tests/smoke.cjs` を通します。ソースのテストと、Workの画像生成・サイト更新は別の確認です。画像が一覧へ自動反映したと報告する前に、Workサイトを再読込して実物を確認します。


## 1媒体から始める・LP入力

新規の初期選択はチラシA4だけで、3案＝3枚です。既存の保存済み選択は保持します。参照LP URLまたは本文から入力案を依頼できます。intake.jsはapp.jsより先に読み込みます。同じSiteへのJSON返送は編集・配信できる場合だけで、できなければJSON/入力案リンクを使います。
