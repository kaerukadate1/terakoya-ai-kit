# 寺子屋AI 第2回｜画像制作ツール ワークショップ用ガイド

## 受講者向け：最短手順

1. **01 素材を入れる**で、イベント名・一番伝えたい言葉・呼びかけを入れます。既存LPがあれば「LP URL」も入れます。
2. **02 構成**で、A4チラシに載せる確定情報を選び、SNSは縦長4:5か横長16:9を選びます。
3. **03 デザイン**で、3案それぞれに「雰囲気」と色を選びます。色は10種類のプリセットから選べ、背景色・アクセント色は自由に変えられます。
4. **04 画像を仕上げる**で生成依頼を開きます。写真を使う場合は、開いたChatGPTの会話に写真を添付してから送ります。
5. 画像を見て、文字・日付・料金・URLに間違いがないか確認します。完成画像は**05 完成画像**で確認します。

## 完成画像の扱い

- チラシはA4の1枚だけで「何の案内か・誰向けか・必要情報・次の行動」が分かることを目標にします。
- SNS画像は投稿本文と一緒に使います。タイトル中心で、詳細を詰め込みません。
- SNSの別比率が必要なら、完成画像の **別比率版を依頼** を使います。開いたChatGPTの会話に元の完成画像も添付し、元画像を残したまま別の比率で再構成した新しい画像を作ります。切り抜き・引き伸ばしではありません。
- LP URLが開けない、または必要情報がLPにない場合は、推測で補わず講師または作成者に確認します。

## 講師用確認リスト

- [ ] 受講者がチラシとSNSで役割が違うことを理解している。
- [ ] SNSの比率（4:5 / 16:9）を用途に合わせて選んだ。
- [ ] 色はプリセットまたは自由配色で選び、3案の違いが見える。
- [ ] 生成依頼には、全体デザインとして作ること、チラシ/SNSを別構成にすることが含まれている。
- [ ] LP URLを使う場合、読めない情報を生成結果が補っていない。
- [ ] 完成画像で文字切れ、誤字、日付・場所・料金・URL、CTA、縮小時の読みやすさを確認した。
- [ ] 別比率版は元画像を残している。

## 困ったとき

| 状況 | まずすること |
| --- | --- |
| 画像が普通の文字だけで弱い | 生成依頼を開き、画像全体として再設計するよう依頼して1案だけ作り直す。 |
| SNSに情報が多すぎる | 日時・料金・URLなどを投稿本文へ回し、タイトル＋短い補足に戻す。 |
| LPを読み込めない | URLと閲覧可否を確認し、必要項目を手入力する。推測で作らない。 |
| 元のSNSを横長/縦長にもしたい | 完成画像から別比率版を依頼する。元画像は削除しない。 |
| 入力が消えたように見える | 同じブラウザ・同じ端末で再読み込みする。別端末には自動同期されない。 |
