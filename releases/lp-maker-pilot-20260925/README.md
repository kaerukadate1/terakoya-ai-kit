# 寺子屋AI LP制作ツール

参加者が開く説明は [lp](../../lp/README.md) です。このフォルダ名は、開始文が取得するパスなので変えていません。

できたLPは、自分の事業にも、依頼を受けたお客様の仕事にも使えます。

参加者へ渡す文は [START_HERE.txt](START_HERE.txt) の2行です。[lp/開始文.txt](../../lp/開始文.txt) と同じ文です。これが [WORKSHOP_PROMPT.md](WORKSHOP_PROMPT.md) を読み、同じフォルダのHTML/CSS/JSを本人限定のWorkサイトとして完成させます。

短文を実行するたびに新しい本人限定サイトを作ります。過去のサイト、入力、完成LPは引き継がず、既存サイトは変更しません。

`index.html` と依存ファイルの相対パスを保持してブラウザで開きます。ローカル表示に外部API、ログイン、デプロイは不要です。`node --test tests/*.test.cjs` で自動テストを実行できます。

実行に必要なものは `index.html`、`styles.css`、`overrides.css`、`core.js`、`library.js`、`app.js`、`completed-lps.json`、`history.json` の8ファイルと、制作ルールとしてWorkが読む `skills/` の3スキル6ファイルです。左サイドバーの「制作一覧」には、保存した制作設定と完成LPが並びます。`sheet.js` はテストが読むため残しています。画面では読み込みません。見本用の画像ファイルは置いていません。写真未指定なら「画像」の仮枠にします。各参加者の入力や写真はGitHubへ保存しません。

ローカルでは3案を比較し、Workでの仕上げは1〜3案から選びます。初期値は1案目だけです。選択状態はその端末の案件データに保存し、Workへの依頼文には選んだ案だけを含めます。

本人限定WorkサイトでLPを仕上げた場合、同サイトの `completed/<一意のID>/index.html` に保存し、実画面のサムネ画像を作れる場合は同じ場所へ保存します。既存LPを消さず、`completed-lps.json` の `entries` に `title`、`design`、`slot`、`url`、`thumbnail`、`createdAt`、`projectSettings` を追記します。設定から再編集する際、画像ファイル本体は再指定します。本人限定で再発行されると、ツールの「完成LP」一覧が画面表示時とフォーカス復帰時に同サイトから読み直します。Workがサイト編集・再発行できない場合は自動登録されないため、リンク登録を使います。ローカルの `127.0.0.1` 版へWorkから直接保存することはできません。

WorkがGitHubからファイルを取得し、Sitesへ保存して非公開で発行します。回答待ちで止めません。アクセスできないときは、再創作やZIPだけで成功扱いにせず、制約を報告します。
