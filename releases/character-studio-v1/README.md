# AIアシスタント設計ツール 配布版

寺子屋AI 第4回 v0.4.0。STARTER_PROMPT.txtとBUILD_PROMPT.mdを使う。画面はdist/、正本はリポジトリのcharacter-studio/。styles.cssとtool-ui.cssは両方配信し、role-skills.jsをcore.jsより先に読む。設定Markdownには30担当それぞれの専門手順（28原典のMIT翻案）を含む。画像は画面操作ではなくreturns/へのファイル返送。Markdownを添付して仕事を依頼し、別の起動文は反映されない時だけ使う。添付だけでプロジェクト指示へ登録される保証はない。

事業・プロジェクトの事前準備なしでアシスタントを設計し、プロフィール・画像・Markdown・共通呼び出し文を保管する。03は設定のみ、04からChatGPTで画像を生成して同じSiteへ返送する。返送はWorkによる同じSiteの編集・配信が必要。非対応時は成功を装わず、手動追加を代替にする。既存データと公開範囲を保持する。
