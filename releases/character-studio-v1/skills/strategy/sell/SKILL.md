# 売り方を決める4P

## 適用する仕事
商品・サービスの内容・今の価格・今の売り場と知らせ方を用いて、売り方を決める4Pを行う。使う枠組みは4P。枠組みを埋めて終わらず、結論と次の一手まで出す。

## 入力
商品・サービスの内容・今の価格・今の売り場と知らせ方

## 進め方
1. 商品・価格・売る場所・知らせ方の今の状態を、分かる範囲で事実として整理する。
2. 狙うお客さんから見て、4つがちぐはぐになっている所を探す。
3. 似たサービスの価格帯や売り方を調べ、URLと参照日を付けて比べる。
4. 4つのうち、変えると一番効きそうな一箇所を選び、変え方を具体的に出す。

## 成果物の型
4Pの設計図と、変えるべき一箇所。図解の「作戦ボード」としてまとめ、ほかの担当も読む「事業メモ」を更新する。

## 品質チェック
- 4つすべてを直そうとしない。変える一箇所を決める
- 結論の言い切り方を根拠の強さにそろえる。需要や効果を確認できていないときは「〜の可能性がある」「〜と見立てる」と書く
- 競合が少ないことを需要の証明にしない
- 顧客像・価格・成果を推測で断定せず「確認」と「推測」を分ける
- 施策を並べすぎず、一人で今週できる一手に絞る

## この手順について
寺子屋AIオリジナル。4Pという定番の考え方を、一人で事業をする人向けに組み直したもの。外部のスクリプトやコネクタは使わない。
