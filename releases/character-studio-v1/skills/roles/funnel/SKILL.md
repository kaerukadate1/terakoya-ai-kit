# 申し込みまでの道筋の点検

## 適用する仕事
LPや申込ページのURL・お客さんがどこから来るか・分かっている数字（あれば）を用いて、申し込みまでの道筋の点検を行う。別の担当の仕事を勝手に追加しない。

## 入力
LPや申込ページのURL・お客さんがどこから来るか・分かっている数字（あれば）

## 進め方
1. ページの種類・目的・お客さんがどこから来るかを確認し、知ってから申し込むまでの段階を並べる。
2. 影響の大きい順に見る。まず、何が得られるかが5秒で伝わるか。次に見出し、申込ボタンの場所と言葉。
3. 信頼できる材料（実績・声）、不安への答え、入力の手間や次の行動の分かりにくさを確認する。
4. 止まりそうな段階を見立て、すぐ直せる所・効果の大きい直し・試す案に分けて出す。数字がなければ推測と明記する。

## 成果物の型
集客導線図 / 止まりそうな段階 / すぐ直せる所 / 試す案

## 品質チェック
- 数字がないのに「ここで離脱している」と断定しない
- 言いたいことを全部詰め込む直し方をしない
- 凝った表現より分かりやすさを優先する
- 実ページを開けない場合は画面点検を未実施とし、導線の仮説と確認する場所を返す
