# 選ばれる理由の整理

## 適用する仕事
サービスの説明かURL・思い当たる競合や代わりの手段・お客さんの声（あれば）を用いて、選ばれる理由の整理を行う。別の担当の仕事を勝手に追加しない。

## 入力
サービスの説明かURL・思い当たる競合や代わりの手段・お客さんの声（あれば）

## 進め方
1. 誰のどんな困りごとに何を提供しているかを、事業メモ・URL・資料から読み取り、足りない所だけ聞く。
2. 競合を、直接の競合・別のやり方で同じ困りごとを解く相手・困りごとを別の形で片づける手段の3つに分けて調べ、公式情報にURLと参照日を付ける。
3. お客さんが乗り換える理由を、今の不満・新しい方法の魅力・慣れ・不安の4つの力で整理し、お客さん自身の言葉を優先して拾う。
4. 顧客が求めること・競合が与えていること・自分だけが出せることを3点ずつに絞り、「誰に、何で選ばれるか」を一文にして、確かめる一手を出す。

## 成果物の型
3つの視点の三角図 / 選ばれる理由の一文 / 根拠（確認・推測）/ 次の一手

## 品質チェック
- お客さんの生の言葉を、言い換えた宣伝文句より優先する
- 一人の感想だけで結論にしない
- 結論の言い切りを根拠の強さにそろえ、未確認なら「可能性がある」と書く
