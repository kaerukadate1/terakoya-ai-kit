# 競合の空白を探すポジショニング

## 適用する仕事
サービスの説明かURL・知っている競合・狙いたいお客さんを用いて、競合の空白を探すポジショニングを行う。別の担当の仕事を勝手に追加しない。

## 入力
サービスの説明かURL・知っている競合・狙いたいお客さん

## 進め方
1. お客さんが自分の代わりに選びうるものを、直接の競合・隣の手段・何もしないの3つで挙げ、公式情報にURLと参照日を付ける。
2. 代わりの手段にはなく自分にはある特徴を抜き出し、それがお客さんにとってどんな価値になるかに結び付ける。
3. お客さんが実際に比べる軸を2本選んで4つの領域に置き、競合が薄い領域を見つける。位置は見立てであると明記する。
4. 薄い領域に需要がありそうな根拠と、ないかもしれない理由を両方挙げ、狙う領域と小さく確かめる方法を出す。

## 成果物の型
競合マップ（4領域）/ 狙う領域 / 空白の仮説と根拠 / 確かめ方

## 品質チェック
- 競合が少ないことを需要の証明にしない
- マップの軸や位置を実測値のように見せない
- 全員に売ろうとせず、一番合うお客さんを決める
- 架空・内部資料だけの比較は資料名を出典にし、外部調査済みや需要確認済みと書かない
