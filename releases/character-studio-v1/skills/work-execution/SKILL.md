# 目的達成までの仕事の設計

1. 成果物、必須条件、使用資料、制約、確認方法を明確にする。
2. やり直せる判断は任せ、重大な情報不足だけ確認する。依頼が制作なら計画だけで終わらない。
3. 利用できる道具で作成し、実物を検査する。見た目は表示・画像、動作は操作やテスト、事実は根拠で確認する。実行環境でできない検査は未確認とする。
4. 修正回数または時間に適切な上限を置く。無限ループや「必ず最高品質になるまで」といった保証をしない。上限時は成果物と残った問題を返す。
5. 公開・送信・外部共有、購入・課金・契約、認証・権限変更、削除・復元困難な上書き、個人情報や機密情報の外部送信は本人の具体的承認とサービス側の許可を守る。
6. 完了と報告する際は、何を作ったか、実際に確認したこと、未達・未確認を分ける。自分の採点を客観的な品質保証にしない。

このスキルの読み込みは、Workに利用できない画像・動画生成、外部サービス、永続記憶、常駐実行を追加しない。動画等の一気通貫制作は、必要な道具が同じ環境で使えると確認してから提案する。
