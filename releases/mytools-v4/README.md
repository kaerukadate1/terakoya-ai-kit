# 寺子屋AI マイサイト v4

旧マイツール仕様を、寺子屋AIのロゴ、深い紺、金の線、明朝見出しを使った固定画面にした版です。マイツール、事業プロフィール、設定、共通告知を含みます。告知は運営の `announcements.json` から取得し、デモと期限外は表示しません。

## ローカル確認

このフォルダで静的サーバーを起動して `index.html` を開きます。例: `python -m http.server 8812 --bind 127.0.0.1`。ローカルでは `localStorage` に保存するため、そのブラウザに残る試作データであり、本人認証や別端末同期はありません。個人情報を入れずに確認してください。

## Work 版

参加者には [START_HERE.txt](START_HERE.txt) の一文だけを渡します。Work は [WORKSHOP_PROMPT.md](WORKSHOP_PROMPT.md) と固定4ファイルを取得し、本人限定認証、サーバー保存、同一オリジンの告知 API を接続します。ローカルの静的版をそのまま外部公開してはいけません。Work のサイト生成やサーバー保存が実際に使えるかは、参加者と同じ権限で通し試験が必要です。

## 旧版との関係

`prompts/01-start-mytools.txt` と `02-mytools-full.txt` は履歴として維持します。本版は v3.1 の共通告知を残し、個人用のツール登録・プロフィール編集・見た目の変更を同じ構造で再現するものです。告知の中身は `announcements.json` を正とし、固定 HTML へ埋め込みません。
