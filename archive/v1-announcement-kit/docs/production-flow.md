# 制作手順：告知文からLP・画像まで

セミナーまるっと用意くんを使い、告知素材から告知文・LP・画像を作る操作手順です。各工程は「操作」と「確認」をセットで行い、次へ進みます。つまずいたときは[トラブル対処](troubleshooting.md)を見てください。

## 工程1　素材と事業情報を入れる

**操作**

1. マイツールを開き、「事業紹介をコピー」を押します。
2. セミナーまるっと用意くんを開き、「事業情報」画面へ貼り付けて保存します。
3. 「告知を作る」画面で、次を入力して保存します。

| 項目 | 入れるもの |
| --- | --- |
| 何を告知したいですか【必須】 | セミナー名とひとこと説明 |
| 詳しい情報 | 対象者、得られること、日時、会場、料金、定員、申込方法 |
| 文体・必ず伝えたいこと | 希望する文体、絶対に入れたい情報 |

日時・料金・定員・会場・申込URLが未定でも、そのまま「未定」で進められます。未定の項目をAIが勝手に作ることはありません。悩んだら[通し実例](../examples/walkthrough.md)の入力例を参考にしてください。

**確認**

- 再読み込みしても入力が残っている。
- 事業情報が正しく取り込まれている（認識できない形式は画面の案内に従う）。

## 工程2　媒体を選んでChatGPTへ送る

**操作**

1. 必要な媒体を選びます。8媒体のうち `checklist`（公開前チェックリスト）は品質確認になるため、毎回選ぶことをおすすめします。
2. 「ChatGPTで開く」を押します。依頼文が入力済みの状態でChatGPTの新しいチャットが開くので、そのまま送信します。依頼ごとに依頼ID（requestId）が発行されます。
3. 依頼文が長くてURLに収まらない場合は、ツールが自動で依頼を分割し、「依頼を送る（1/2）」「（2/2）」のように順に開くボタンを出します。番号順に開いてそれぞれ送信します。返ってきたJSONはどれも同じ手順で取り込めば、同じ依頼へ自動でまとまります。

**確認**

- 開いたチャットの入力欄に、自分の素材と事業情報が入った依頼文が入っている。
- 選んだ媒体だけが依頼に含まれている。

## 工程3　JSONを取り込む

**操作**

1. ChatGPTが返したJSONのコードブロックをコピーします（返答の末尾に貼り付け先の案内が出ます）。
2. ツールの「結果の取り込み」欄へ貼り付けます。
3. 確認画面で内容と注意事項（warnings）を読み、問題なければ「取り込む」を押します。

**確認**

- 依頼IDが一致している。違う場合は取り込まず、正しい依頼への返答を取り直します（[トラブル対処](troubleshooting.md)）。
- 一部の媒体だけ返ってきた場合は、受領分と未受領分が画面で区別されている。未受領分は同じ依頼IDで再度依頼します。
- 再読み込みしても取り込んだ文章が残っている。

## 工程4　文章の品質を確認する

**操作**

1. [品質チェック](quality-checklist.md)の媒体別チェックポイントで、取り込んだ文章を確認します。
2. 直したい媒体がある場合は、同じ依頼IDでその媒体だけ書き直しを依頼します（指示例は[生成指示の仕様](generation-spec.md)の「やり直し」）。

**確認**

- 日時・料金・申込先が実際の予定と一致している（未定は「未定」のまま）。
- 事業情報の強み・文体・避けたい表現が反映されている。

## 工程5　告知LPを作る

**操作**

1. ツールの lp 結果にある「ChatGPTで開く」を押します。依頼文が入っていない・途中で切れている場合は、依頼履歴に残る依頼文の全文を写してChatGPTのワークへ貼り付けます。
2. 手動で進める場合は [04-create-lp.txt](../prompts/04-create-lp.txt) を貼り、そのあとにLP原稿を貼って送信します。
3. 返ってきた確認用URLを開き、PCとスマートフォンで表示を確認します。
4. 確認用URLを、ツールのlp結果の「完成URL」へ記録します。

**確認**

- 参加対象、得られること、内容、開催情報、申込導線の順に並んでいる。
- 申込先が決まっている場合だけ申込ボタンが動く。未定なら「受付準備中」などの表示になっている。
- 文章の出力やコード提示だけではこの工程は完了しません。実際に表示できるLPが必要です。

## 工程6　チラシ・SNS画像を作る

**操作**

1. ツールの該当結果にある「ChatGPTで開く」を押します。依頼文が入っていない・途中で切れている場合は、依頼履歴に残る依頼文の全文を写してChatGPTのワークへ貼り付けます。
2. 用途ごとの寸法を指定します。目安は次の表です。

| 用途 | 目安 |
| --- | --- |
| SNS投稿（Instagram等） | 正方形 1080×1080 |
| X・LINE | 横長 1200×675 前後 |
| チラシ | A4縦。印刷に使う場合は印刷先の解像度・余白・形式を別途確認 |

3. できた画像で、セミナー名・日付・場所・参加方法が読めるか、文字の誤りや切れがないかを確認します。問題があれば修正を依頼します。
4. 完成ファイル（PNG・JPEG・WebP、10MB以下）をツールへアップロードし、該当する結果へ関連付けます。

**確認**

- ロゴや写真は使用できる素材だけを渡している。
- デモ素材で試している場合は、画像にも「デモ」と入っている。

## 工程7　完成状態と履歴を確認する

**操作**

1. ツールで、各結果に完成URL・完成ファイルが関連付いているかを一覧で確認します。
2. 原稿を変更した場合は、完成物が「変更前の原稿によるもの」と表示されることを確認し、必要なら工程5・6をやり直します。
3. 「履歴」画面で過去の告知を開き、原稿・完成URL・画像が再参照できること、依頼履歴に依頼ID・媒体・返却状況が残っていることを確認します。

**確認**

- 投稿文・画像の完成と、SNSへの投稿完了は別です。投稿は別途、本人が行います。
- 未作成の成果物に架空URLを入れていない。
- 「新しい告知を作る」を押すと、現在の告知が履歴へ保存されてから新規が始まる。

## SNS投稿・共通告知との関係（運営向け）

公開済みの告知LPをdetailUrl、公開済みの関連SNS投稿をsnsUrlへ設定すると、共通告知から両方を開けます。SNS投稿前はsnsUrlを空文字（""）にします。共通告知は運営が選んだ内容を配信する仕組みであり、参加者が作った告知を自動で全員のマイツールへ掲載しません。

運営の通し確認とキャプチャ記録は[検証チェックリスト](verification.md)に従ってください。
