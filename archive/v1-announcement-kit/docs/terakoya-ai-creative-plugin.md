# 寺子屋AI クリエイティブプラグイン

ChatGPT Workで制作する告知文、LP、Webサイト、本人専用ツールの品質を上げるためのプラグインです。

## 入っているスキル

| スキル | 用途 |
| --- | --- |
| 寺子屋AI コピーライティング | 事実を創作せず、自然な日本語と媒体に合う導線へ整える |
| 寺子屋AI Webデザイン | 事業固有のデザイン、モバイル表示、Sites制作を整える |
| 寺子屋AI クリエイティブレビュー | 文章・デザイン・導線・事実を優先度付きで確認し、修正する |

3つは `plugins/terakoya-ai-creative/skills/` にあり、1つのプラグインとしてまとめています。

## インストールテスト

このリポジトリのマーケットプレイスをChatGPTまたはCodexへ追加し、「寺子屋AI クリエイティブ」をインストールします。インストール後は新しいWorkチャットを開いてください。

表示や共有方法はChatGPTの更新で変わる可能性があるため、当日はプラグイン画面に表示される案内を優先します。

## 動作確認

### 1. コピーライティング

次を依頼します。

```text
寺子屋AI コピーライティングを使って、次のイベントのLINE告知文を作ってください。
日時：未定
料金：3,000円
内容：スマートフォンの商品撮影講座
```

確認すること：

- 日時を創作しない。
- 料金を正確に使う。
- LINE向けの短く自然な文章になる。
- 必要なら日時が未定であることを示す。

### 2. Webデザイン

次を依頼します。

```text
寺子屋AI Webデザインを使って、小さな陶器店の商品紹介LPのデザイン方針を作ってください。
スマートフォンを優先し、商品写真を主役にしてください。
```

確認すること：

- 陶器店に由来する具体的な方針になる。
- 配色、書体、レイアウト、記憶点が整理される。
- 一般的なAIサイトの装飾を無条件に足さない。

### 3. クリエイティブレビュー

作成済みの文章、画像、サイトのいずれかを添えて、次を依頼します。

```text
寺子屋AI クリエイティブレビューを使って、公開前に確認し、P0からP3で指摘してください。直せる部分は修正してください。
```

確認すること：

- 事実、コピー、デザイン、モバイル、導線を分けて確認する。
- 問題の場所、理由、具体的な修正が示される。
- 実際に確認できない内容を「確認済み」にしない。

## 告知一式での使い方

- 「セミナーまるっと用意くん」で告知文を作るときはコピーライティングを使う。
- LPをSitesで作るときはコピーライティングとWebデザインを使う。
- 告知文、LP、画像を完成扱いにする前にクリエイティブレビューを使う。

Sitesはサイト制作と保存を担当し、このプラグインは文章・デザイン・レビューの判断を担当します。
