# 品質チェック

できあがった文章・LP・画像を、公開前に自分で確認するためのリストです。AIの出力はそのまま公開せず、必ずこのチェックを通してください。

## すべての成果物に共通

- [ ] 日時・料金・定員・会場・申込先が自分の予定と一致している（未定は未定のまま）
- [ ] 素材に書いていない実績・数字・お客様の声が入っていない
- [ ] 「必ず」「絶対」「満席保証」などの誇大表現がない
- [ ] 「本質は」「課題解決」「価値提供」など、教祖調・営業調の決まり文句がない
- [ ] 冒頭が抽象的な宣言ではなく、具体物・数字・読者の状況から始まっている
- [ ] 不安をあおるだけで終わらず、「次に何をすればいいか」が示されている
- [ ] 媒体が違っても「一番伝えたいこと」がぶれていない
- [ ] 事業名・自分の名前・連絡先に誤りがない
- [ ] プロフィールの「避けたい表現」が使われていない
- [ ] ツールの確認画面の warnings に未対応の指摘が残っていない

## 媒体別

### copy（汎用告知文）

- [ ] 「何を・誰に・いつ・どこで・いくら・どう申し込むか」がすべてある
- [ ] そのままチラシや口頭案内に転用できる素直さがある

### email（メール案内）

- [ ] 件名が30字以内で、開く理由が分かる
- [ ] 冒頭で何の案内か分かる
- [ ] 申込方法が1箇所、明確に書かれている
- [ ] 署名欄がある

### flyer（チラシ文言）

- [ ] 大見出しがセミナー名になっていて目立つ
- [ ] 日時・会場・料金・申込方法が箇条書きでまとまっている
- [ ] 文字が詰め込まれすぎていない

### lp（告知LP原稿）

- [ ] 8セクション（キャッチ→こんな方へ→得られること→内容→講師→開催情報→CTA→FAQ）が揃っている
- [ ] キャッチコピーだけで「誰向け・何が得られるか」が分かる
- [ ] 開催情報が表形式で一覧できる
- [ ] FAQが想定される質問になっている

### x（X投稿文）

- [ ] 140字以内に収まっている
- [ ] 冒頭1行で関心を引ける
- [ ] 日時と申込先（またはLP案内）が入っている

### instagram（キャプション）

- [ ] 本文が300字以内で改行があり読みやすい
- [ ] ハッシュタグが5〜10個ある
- [ ] 絵文字の量が自分の文体に合っている

### line（LINE配信文）

- [ ] 200字以内で、要点→日時→申込URLの順になっている
- [ ] 近しい相手に送れる文体で、押しつけがましくない

### checklist（公開前チェックリスト）

- [ ] 実際に各項目を「確認した」状態になるまで公開しない

## LP（完成ページ）

- [ ] PCとスマートフォン（390px幅相当）の両方で崩れず表示できる
- [ ] ファーストビューが「約束1つ＋申込導線1つ」に絞られている
- [ ] 文字を小さくして詰め込んでいる部分がない
- [ ] 申込導線が序盤と末尾にある
- [ ] 日時・料金・申込先が画像ではなくテキストとして残っている
- [ ] 申込ボタンが実際の申込先へつながる（未定なら「受付準備中」等の表示）
- [ ] デモ素材で試した場合、どこかに「デモ」と分かる表示がある
- [ ] 確認用URLがツールの結果へ記録されている

## 画像（チラシ・SNS）

- [ ] スマートフォン表示（390px幅相当）でセミナー名が最も大きく読める
- [ ] 日付・場所・参加方法が読める
- [ ] 読める文字が最小限で、意味のない飾り文字・偽の日本語がない
- [ ] 文字の誤り・切れ・にじみがなく、重要な文字が端から離れている
- [ ] 複数枚ある場合、色・フォント感・レイアウトに統一感がある
- [ ] 実際に押せるボタン・フォームに見える装飾がない
- [ ] 用途の寸法に合っている（[制作手順](production-flow.md)のサイズ表）
- [ ] 使用許可のないロゴ・写真が入っていない

## 直したいときは

全部を作り直す必要はありません。同じ依頼IDで、その媒体だけ書き直しを依頼できます。方法は[生成指示の仕様](generation-spec.md)の「やり直し」を参照してください。
