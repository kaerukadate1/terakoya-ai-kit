# トラブル対処

つまずいたときの症状別の対処です。解決しない場合は、何をしたか・何が表示されたかを記録して運営へ共有してください。

## サイト作成中（STEP 2・3）

| 症状 | 考えられる原因 | 対処 |
| --- | --- | --- |
| AIが仕様を読めない・読んだふりをする | GitHubのファイルを取得できていない | 完全版のプロンプトと該当仕様をそのまま貼って渡す。マイツールは `archive/v1-announcement-kit/prompts/02-mytools-full.txt` と `archive/v1-announcement-kit/docs/announcements.md`、セミナーまるっと用意くんは `archive/v1-announcement-kit/docs/seminar-spec.md`・`archive/v1-announcement-kit/docs/generation-spec.md`・`archive/v1-announcement-kit/docs/registration.md`・`archive/v1-announcement-kit/docs/production-flow.md` |
| 制作が始まっても質問が出ない | AIが完成まで質問を保留している | 「事業名の質問を今出してください」と一言送る。初版の実測でも同じつまずきがあり修正済み |
| 一度にたくさん質問される | 「1問ずつ」の指示が伝わっていない | 短く「1問ずつ聞いてください」と送る |
| 回答すると別サイトが新しく作られる | 同じサイトへの反映指示が効いていない | 「別サイトを作らず、制作中の同じサイトへ反映してください」と送る |
| 「裏で制作中」と出たまま進まない | 実際には処理していない可能性 | 新しいメッセージで現在の状態を聞く。実測で未処理のまま表示する例があった |

## 告知文の生成（STEP 4・工程1〜4）

| 症状 | 考えられる原因 | 対処 |
| --- | --- | --- |
| 「ChatGPTで開く」を押しても依頼文が入っていない・途中で切れている | URLの長さ制限（依頼文が長すぎる） | 8,000文字を超える依頼はツールが自動で分割して順に開く。分割されず途中で切れた場合は、依頼履歴の依頼詳細に残る依頼文の全文を写してChatGPTへ貼り付ける |
| ボタンを押しても反応が見えない | 押下フィードバック不足 | コピー・保存は押すと状態表示が出る仕様。見た目に反応がない場合は再読み込みで保存状態を確認し、再発するなら運営へ報告 |
| 「制作へ進む」などのボタンが押せないまま | ChatGPT未ログイン、または必須欄の未入力で無効化されている（2026-09-22テスト会で発生） | 本人がログインしたブラウザで開き直す。材料の必須欄（何を告知したいか）を入力する。ツールは無効の理由と次の操作をボタン近くに表示する仕様のため、理由表示がない場合は運営へ報告 |
| 前に作った告知の結果が見つからない | 履歴画面を見ていない | 「履歴」画面から過去の告知を開く。「新しい告知を作る」を押しても内容は履歴へ保存される |
| JSONが返ってこない・文章で返る | 返却形式が守られていない | 「指定どおりコードブロックのJSONだけを返してください」と送る。返答末尾の案内文は取り込み時に不要 |
| 取り込み時に「依頼IDが違う」と出る | 別の依頼への返答を貼っている | 無理に書き換えて取り込まない。依頼IDが一致する返答をChatGPTから取り直す |
| 一部の媒体しか返ってこない | ChatGPTが全媒体を返さなかった | 受領分を取り込み、未受領の媒体だけを同じ依頼IDで再度依頼する |
| 返ってきた文章に未定の情報が入っている | 素材の「未定」が指示へ反映されていない | 素材の未定項目を確認して保存し直し、生成指示を作り直す。取り込み前の確認画面でwarningsも読む |
| 事業情報を貼っても取り込まれない | コピー形式が認識されていない | 「【事業名】と次行の値」「事業名：値」「番号付きシート」のいずれかの形で貼り直す |
| 保存したはずが再読み込みで消える | 保存が失敗している | 保存時のエラー表示を確認。入力は保持される仕様なので、消えた場合は運営へ報告 |

## LP・画像（STEP 5・6）

| 症状 | 考えられる原因 | 対処 |
| --- | --- | --- |
| LPの文章やコードだけ返ってきてサイトができない | Sitesでの実作成まで進んでいない | 「Sitesで実際に作成して、確認用URLを示してください」と送る |
| 申込ボタンがあるのに申込先が未定 | 未定項目が創作された | 「申込先は未定です。受付準備中の表示に直してください」と送る |
| 画像の文字がおかしい・切れている | 画像生成の文字精度 | 「直す点と残す点」を分けて修正を依頼する。入れる文字を減らすと安定する。それでも駄目なら文字なし画像＋テキストは別途載せる |
| 複数枚の画像の雰囲気がバラバラ | 一括生成・方向未固定 | 最初の1枚で気に入ったものを選び、「この画像と同じ雰囲気で」と伝えて残りを作り直す |
| 完成URLやファイルを保存したのに結果と結びつかない | 関連付けの操作漏れ | 該当する結果を開き、完成URL欄・ファイル欄へ登録し直して再読み込みで確認 |

## 共通告知・その他

| 症状 | 考えられる原因 | 対処 |
| --- | --- | --- |
| 共通告知が表示されない | 配信期間外・JSON不正・反映待ち | announcements.json の startsAt/endsAt と形式を確認。更新反映は即時ではなく数分かかる場合がある |
| 告知の更新がサイトに出ない | キャッシュ・再取得タイミング | 1分待つか、ウィンドウを一度離れて戻ると再取得される |
| 「保存」と「公開」の違いが分からない | バージョン保存＝本人の作業保存、公開＝外部へ出す操作 | このキットでは公開は別操作です。参加者はバージョン保存まで行い、公開は運営と確認してから行います |
