# 通し検証チェックリスト

この一覧は実施前の確認項目です。チェックを付けるのは実際に確認してからです。対象の仕様版、サイト版、端末幅、日時、実施者、結果、キャプチャ、残件を記録します。

## 1. 制作中のヒアリング

- [ ] 事業名の回答前に、共通部分の実際の制作が始まった。
- [ ] 質問が一問ずつ示され、途中回答を受け取れた。
- [ ] 両方を一度に答えた場合は再質問しなかった。
- [ ] 回答が同じサイトへ反映され、別サイトを増やしていない。
- [ ] 回答前に終わった場合は下書き保存と回答待ちを正しく伝えた。
- [ ] 本人情報を変えても再読込・再デプロイで元へ戻らない。

## 2. 公開GitHubから再現

- [ ] ログインなしでREADMEと参照仕様を取得できた。
- [ ] 短い指示だけで仕様を読み、適用版を記録した。
- [ ] 参照できない場合の完全版貼り付けで進められた。
- [ ] 3画面、項目名、空のツール一覧、本人限定保存が一致した。
- [ ] 公開ファイルに個人情報、内部資料、秘密が含まれない。

## 3. ツール登録と生成結果

- [ ] 新名称でツールを登録・再読込・起動できた。
- [ ] 不正URLと重複URLを検知した。
- [ ] 事業紹介をコピー・貼付・保存できた。
- [ ] 素材入力の各項目に良い例・悪い例が表示された。
- [ ] 生成指示が generation-spec.md の構造（依頼ID・プロフィール・素材・共通ルール・選択媒体のブロック・返却形式・返却後の案内・セルフチェック）に従っていた。
- [ ] 「ChatGPTで開く」で依頼文入りのチャットが新しいタブで開いた。「依頼文をコピー」等のコピー専用ボタンが画面になかった。
- [ ] 8,000文字を超える依頼は同じ依頼IDで自動分割され、順に開くボタンから各部分を送信できた。
- [ ] 素材入力の各欄が空で開始し、「テスト用」「サンプル入力」などの要素や初期値がなかった。
- [ ] 「結果の取り込み」欄が「ChatGPTで開く」と同じ画面にあり、開く→送信→貼る→取り込むが1画面で完結した。
- [ ] 返答末尾に「JSONをツールの取り込み欄へ貼る」案内が1行添えられていた。
- [ ] 「ChatGPTで開く」→ 送信 → 実際のChatGPT出力 → JSON確認 → 取り込み → 再読込を通した。
- [ ] 返却JSONに warnings が含まれ、確認画面で本文と併せて表示された。
- [ ] 不正JSON、別依領ID、重複媒体、未依頼媒体、古い返却を拒否または明示した。
- [ ] 一部媒体だけの返却で未受領分を残した。
- [ ] 同一依頼IDでの部分再依頼で、対象媒体だけが更新され他の結果が保持された。
- [ ] 保存失敗時に入力が消えず、成功と表示しなかった。
- [ ] すべてのボタンに押下フィードバックがあり、押せない・使わないボタンが画面になかった。

## 4. 共通告知

- [ ] PC左下とスマートフォンで操作を妨げずに表示された。
- [ ] 詳細URLとSNS URLが実際の対象を開いた。
- [ ] 未設定リンクを表示せず、デモを明示した。
- [ ] 公開JSONだけを更新し、2つのサイトへ反映した。
- [ ] 開始前・期限終了・不正データ・取得失敗・空配列を扱えた。
- [ ] 告知の障害時もプロフィール保存とツール起動ができた。

## 5. 完成物

- [ ] 告知文だけでなく、実際のLPを作成した。
- [ ] LPのPC・スマートフォン表示、開催情報、申込導線を確認した。
- [ ] LPが8セクション構成（キャッチ→こんな方へ→得られること→内容→講師→開催情報→CTA→FAQ）に沿っていた。
- [ ] チラシ画像とSNS画像を生成し、文字と表示を確認した。
- [ ] 画像が用途の寸法に合い、セミナー名・日付・場所・参加方法が読めた。
- [ ] 完成物を該当する結果へ関連付け、再訪して開けた。
- [ ] 公開前チェック画面で未定項目・未対応warnings・デモ表記・未関連付けを確認できた。
- [ ] 「新しい告知を作る」で現在の告知が履歴へ保存され、履歴画面から素材・依頼文・原稿・完成URL・画像をいつでも再参照できた。
- [ ] 依頼履歴にrequestId・媒体・発行日時・返却状況・依頼文全文が表示され、未返却の依頼が追跡できた。
- [ ] 未定・デモ・未公開・未投稿を完了表示と混同していない。

## 6. 参加者条件とキャプチャ

- [ ] 運営の権限だけでなく、想定する参加者の利用条件を記録した。
- [ ] 本人の画面・API・画像が、非ログイン者や別利用者から読めなかった。
- [ ] 作成開始、質問、回答反映、登録、依頼送信、JSON取り込み、LP、画像、告知表示を撮影した。
- [ ] 各キャプチャに「操作」と「確認できる結果」を付けた。
- [ ] 各工程の所要時間と待ち時間を実測した。
- [ ] 2時間の枠で完了した範囲と残った範囲を分けて記録した。
- [ ] つまずきへの戻り先・代替手順を記録した。

実施できない確認は「未検証」とし、理由と次の確認方法を残します。別アカウントがない状態で、参加者の本人限定アクセスを確認済みにしません。
