# マイツールへ登録する

1. 作成したセミナーまるっと用意くんを開き、本人の権限で利用できることを確認します。
2. ツールの利用URLをコピーします。編集画面のURLや一時プレビューと、利用URLを混同しないでください。
3. マイツールの「＋ツールを追加」で次を登録します。

| 項目 | 内容 |
| --- | --- |
| 名称 | セミナーまるっと用意くん |
| ツールURL | 今回作成して確認した利用URL |
| 説明 | セミナーの告知文・LP・画像を、事業情報からまとめて用意します。 |
| 使い方・作り方のメモ | 事業紹介をコピーし、告知素材を入力。ChatGPTに依頼し、結果を取り込みます。 |
| 説明ページのURL | https://github.com/Kaeruka/terakoya-ai-kit/blob/main/archive/v1-announcement-kit/docs/production-flow.md |

4. 保存後に再読み込みし、カードが残ることを確認します。
5. カードの「開く」から別タブで起動し、入力・生成指示のコピー・JSON取り込み・保存を一度通します。

事業情報はマイツールの「事業紹介をコピー」からツールの「事業情報」へ貼り付けて保存します。片方の編集がもう片方へ自動反映される仕様ではありません。

同じURLを追加した場合は重複確認を出します。登録解除は一覧から外す操作で、元のサイトは削除しません。
