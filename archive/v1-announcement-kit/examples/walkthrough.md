# 通し実例：素材入力から完成まで

**デモ・架空の例です。実在する事業・セミナーではありません。**

素材を入れてからLP・画像まで行く、一連の流れの実例です。自分の作業と見比べる参考にしてください。

## 1. ツールへ入れた素材

| 項目 | 入力した内容 |
| --- | --- |
| 何を告知したいですか | はじめてのLINE公式アカウント活用セミナー。店舗を持つ個人事業主向けに、開設から最初の配信までを90分で体験してもらう会 |
| 詳しい情報 | 対象：店舗型の個人事業主。得られること：アカウント開設と初回配信の手順。日時：2026年10月20日(火)14時〜。会場：市内産業会館3階。料金：3,000円。定員：未定。申込：メールで受付（demo@example.com） |
| 文体・必ず伝えたいこと | ていねいで親しみやすい文体。「パソコンが苦手でも大丈夫」と必ず伝える |

事業情報（マイツールからコピーしたもの）：

```
事業名：さくら経営サポート
事業・サービス内容：店舗型の個人事業主に、ITツールの導入と集客の仕組みづくりを支援しています
希望する文体：ていねいで親しみやすく。専門用語にかならず補足をつける
避けたい表現：バズる、爆益、放ったらかしで稼ぐ
```

## 2. ツールが作った生成指示（一部抜粋）

媒体は `email` `x` `lp` `checklist` を選択した例です。

```
あなたは中小企業・個人事業主向けの告知文を作るライターです。
依頼ID: r-20261001-003

【事業プロフィール】
（上記の事業情報がそのまま入る）

【告知素材】
（上記の素材がそのまま入る）

【一番伝えたいこと】
パソコンが苦手な人でも、LINE公式アカウントの開設から初回配信まで90分で体験できる

【共通ルール】
- 「未定」と記載した項目は、日時・料金・定員・会場・申込先を含め創作しないでください。…
- 不安をあおって追い立てる書き方はせず、読者の不安を「次の一歩」へつなぐ書き方にしてください。…
- 文体は【事業プロフィール】の「希望する文体」に従ってください。…
- 「避けたい表現」に挙げた言葉・表現は使わないでください。
- これはデモ素材です。すべての出力に読み手がデモと分かる表記を入れてください。

【作ってほしいもの】
- id: email　メール案内。…
- id: x　X（Twitter）投稿文。140字以内。…
- id: lp　告知LPの原稿。…
- id: checklist　この告知を公開する前に確認すべき項目のチェックリスト。…

【返却形式】
次のJSONをコードブロックで返してください。
{"requestId":"r-20261001-003","results":[{"id":"媒体ID","text":"本文","warnings":["注意点"]}]}

【返却後の案内】
コードブロックの外に、利用者への次の一手を1行で添えてください：「このJSONをコピーして、セミナーまるっと用意くんの『結果の取り込み』欄に貼り付け、確認画面で『取り込む』を押してください」
```

なお、この依頼文はツールの「ChatGPTで開く」ボタンで `https://chatgpt.com/?q=` 付きのリンクとして開き、そのまま送信します。URLに収まらない長い依頼はツールが自動で分割し、順に開くボタンを出します。返ってきたJSONは同じ画面の「結果の取り込み」欄へ貼り付けます。

## 3. ChatGPTが返したJSON

```json
{"requestId":"r-20261001-003","results":[
{"id":"email","text":"件名：【10/20(火)】LINE公式アカウント、はじめの一歩を90分で【デモ】…","warnings":["定員が未定のため「定員」を記載していません"]},
{"id":"x","text":"【デモ】パソコンが苦手でも大丈夫。LINE公式アカウントの開設から初回配信まで90分で体験できます。10/20(火)14時〜 市内産業会館。詳細・申込はこちら","warnings":[]},
{"id":"lp","text":"## キャッチコピー\n…","warnings":["講師紹介はプロフィール記載の範囲のみです"]},
{"id":"checklist","text":"- 日時と会場が素材と一致するか確認した\n- 申込メールアドレスが正しいか確認した\n…","warnings":[]}
]}
```

ポイント：依頼IDが一致している、選んだ4媒体だけが返っている、未定の定員がwarningsで明示されている。

## 4. LP作成の指示（[04-create-lp.txt](../prompts/04-create-lp.txt) を使用）

```
（04-create-lp.txt の内容を貼り、そのあとに取り込んだlpの本文を貼る）
```

## 5. 画像作成の指示（[05-create-images.txt](../prompts/05-create-images.txt) を使用）

```
（05-create-images.txt の内容を貼り、flyerかxの本文を貼る。用途：Instagram用の正方形）
```

生成された画像でセミナー名の文字を確認し、「デモ」の表記が入っていることを確認してからツールへアップロードしました。
