# lp を直す人へ

このフォルダ内が編集元です。app/ は画面、prompts/ は制作指示・配布版README、skills/ は本ツールのスキル、tests/ はテストです。実在しない項目の空フォルダは作りません。開始文.txt の既存URLと正本の位置は維持しています。

release-map.json が各正本と従来の配布先を1対1（共用スキルは1対多）で定義します。releases/lp-maker-pilot-20260925/ は生成先で直接編集しません。

```sh
node scripts/generate-tool-release.cjs lp --write
node scripts/generate-tool-release.cjs lp --check
```

--check（省略時も同じ）は読み取りのみです。--write は明示された対応表だけを書き出し、削除しません。全正本を読んでから書き込みます。今回の移行では配布先の全ファイルをバイト単位で維持しました。

テストと配布スクリプトは従来の配布配置の相対パスを使うため、生成後にrelease側で実行します。編集はこのフォルダ内の正本で行ってください。タグや固定URLの差し替え、Siteの公開設定の変更はこの生成処理に含みません。完成物・顧客情報・Site識別子を追加しません。

LP共用スキルは lp/skills/ が唯一の正本です。plugin/ には既存プラグイン定義と説明だけを置きます。従来の plugins/terakoya-ai-creative/ とreleaseのskills/へ同じ正本から生成します。marketplaceのパス・plugin定義の内容・権限は変更していません。

検証: node --test releases/lp-maker-pilot-20260925/tests/*.test.cjs
