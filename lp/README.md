# LPを作る

本人専用のLP制作ツールを作り、3案を比べて、選んだ1〜3案のLPを仕上げます。

できたLPは、自分の事業にも、依頼を受けたお客様の仕事にも使えます。

## 最初に開くもの

- [開始文](開始文.txt)：Workへ貼る文です。配られたファイルから全文をコピーします。Zoomのチャットからはコピーしません。
- [手順](手順.md)：初めての人向けです。
- [進行](進行.md)：当日の順番です。
- [スキル](スキル.md)：文章、デザイン、仕上げ前の確認です。

画面と制作指示は [releases/lp-maker-pilot-20260925](../releases/lp-maker-pilot-20260925/README.md) にあります。フォルダ名は、開始文が取得するパスなので変えていません。
