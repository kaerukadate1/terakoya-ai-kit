# 寺子屋AI 制作キット

## マイサイト固定版 v4

寺子屋AIのデザインを備えた本人用マイサイトの固定版は [releases/mytools-v4/](releases/mytools-v4/) にあります。ワークショップで渡す短い文は [START_HERE.txt](releases/mytools-v4/START_HERE.txt)、Workが読む詳細指示は [WORKSHOP_PROMPT.md](releases/mytools-v4/WORKSHOP_PROMPT.md) です。旧マイツール仕様は履歴として残しています。固定版をローカル表示しただけでは本人限定認証やサーバー保存は成立しません。

ChatGPTのワークとSitesで、自分専用の「マイツール」と「セミナーまるっと用意くん」を作り、セミナーの告知文・LP・画像まで用意するための共通仕様です。

## 全体像

```
STEP2  マイツールを作る ──→ 事業プロフィール＋AIツール一覧のサイト
STEP3  セミナーまるっと用意くんを作る ──→ 素材入力→生成指示→JSON取り込みのサイト
STEP4  ツールに素材を入れて告知文を作る ──→ 8媒体分の原稿が保存される
STEP5  LPを作る ──→ お客様向けの告知ページ
STEP6  画像を作る ──→ チラシ・SNSに使う画像
```

## 用語集

| 用語 | 意味 |
| --- | --- |
| ワーク | ChatGPTの作業スペース。指示を貼ってサイト制作を依頼する場所 |
| Sites | ワークの中で実際のWebサイトを作成・保存する機能 |
| マイツール | あなた専用のサイト。事業プロフィールとAIツール一覧を持つ |
| セミナーまるっと用意くん | あなた専用のサイト。告知素材を入れ、ChatGPTへの依頼文と結果を管理する |
| 依頼ID（requestId） | 生成指示ごとに発行される番号。返ってきたJSONと照合する |
| 共通告知 | マイツールの左下に表示される、寺子屋AI運営からのお知らせ |

## 手順

各STEPは「やること → 使うもの → 終わった目安」の順です。つまずいたら[トラブル対処](docs/troubleshooting.md)を見てください。

### STEP 1　準備する

- やること：ChatGPTのワークで、Sitesを使える状態にします。
- 終わった目安：新しいワークで `@Sites` の指示を送れる。

### STEP 2　マイツールを作る

- やること：ワークに [01-start-mytools.txt](prompts/01-start-mytools.txt) を貼り付けます。制作が始まったら、事業名と事業内容を聞かれるので答えます。
- 使うもの：`prompts/01-start-mytools.txt`
- つまずいたら：AIが仕様を読めない場合は [02-mytools-full.txt](prompts/02-mytools-full.txt) と [共通告知仕様](docs/announcements.md) をそのまま貼って渡します。
- 終わった目安：3画面（マイツール・事業プロフィール・設定）のサイトがバージョン保存されている。

### STEP 3　セミナーまるっと用意くんを作って登録する

- やること：ワークに [03-start-seminar.txt](prompts/03-start-seminar.txt) を貼り付け、できたツールを[マイツールへ登録](docs/registration.md)します。
- 使うもの：`prompts/03-start-seminar.txt`
- 終わった目安：マイツールの一覧に「セミナーまるっと用意くん」のカードがあり、「開く」で起動できる。

単ファイル配布版として [terakoya-kokuchi-v3.1-work-pack.txt](releases/kokuchi-v3/terakoya-kokuchi-v3.1-work-pack.txt)（識別子 `TERAKOYA-V3-WORKSHOP-03`、現在 v3.2 作業中）もあります。`releases/kokuchi-v3/` の V3 パックの改訂版で、受渡しは `?prompt=` リンク、GitHub参照による制作を主経路とし（添付は代替）、結果は Work からの直接返却・自動保存でサイドバーに蓄積する設計へ移行中です。ヒアリングシート同梱、名前付き「告知一式」保存セット、材料欄の「ChatGPTに相談する」ボタンなど `docs/` 側の現行仕様と一部異なります。相談文テンプレート（`prompts/06-consult-material.txt`）と制作ルール（`prompts/terakoya-creative-rules.txt`）はツールが実行時に GitHub から読み込む設計です。配布にはどちらの版を使うか運営で確認してください。

### STEP 4　告知文を作る

- やること：ツールに告知素材と事業情報を入れ、媒体を選び、「ChatGPTで開く」で依頼を送り、返ってきたJSONを取り込みます。
- 使うもの：セミナーまるっと用意くん（操作の詳細は[制作手順](docs/production-flow.md)）
- 終わった目安：選んだ媒体の文章がツールに保存され、再読み込みしても残っている。

### STEP 5　告知LPを作る

- やること：保存したLP原稿をもとに、ワークへ [04-create-lp.txt](prompts/04-create-lp.txt) を貼って実際のLPを作り、確認用URLをツールへ記録します。
- 使うもの：`prompts/04-create-lp.txt`
- 終わった目安：PC・スマートフォンで表示したLPのURLが、ツールの結果に関連付いている。

### STEP 6　チラシ・SNS画像を作る

- やること：保存した原稿をもとに、ワークへ [05-create-images.txt](prompts/05-create-images.txt) を貼って画像を生成し、ツールへアップロードします。
- 使うもの：`prompts/05-create-images.txt`
- 終わった目安：文字の誤りや切れのない画像ファイルが、ツールの結果に関連付いている。

このキットを参照しただけで、サイトの作成・公開やSNS投稿が完了するわけではありません。作成されたサイトと保存状態を確認して利用を始めてください。

## できあがるもの

- 本人専用のマイツール：事業プロフィールとツール一覧。
- 本人専用のセミナーまるっと用意くん：素材を整理し、ChatGPTへ渡す指示を作り、返ってきた結果を保存。過去の告知と依頼は履歴として残る。
- お客様向けの告知LPと、チラシ・SNSに使う画像。
- マイツール左下に表示する、寺子屋AIの共通告知。

本人専用の情報は公開リポジトリへ入れません。公開LPには掲載を決めた情報だけを使います。

## 仕様の更新

初回制作は公開リポジトリの仕様を参照します。運営が検証した版を配布するときは、ブランチ名ではなくタグまたはコミットを固定したURLに置き換えてください。共通告知だけは更新用のJSONを実行時に読みます。既存サイトのプログラムがGitHub更新だけで自動更新される仕組みではありません。

本資料は仕様と手順です。各環境での動作確認結果は、実施日・対象版・実際の結果を分けて記録してください。
