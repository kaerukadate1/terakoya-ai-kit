# 寺子屋AI 制作キット

ChatGPT WorkとSitesで、本人専用の制作ツールを作り、LPやチラシ・SNS画像を仕上げるキットです。作りたいものを1つ選び、その開始文をWorkへ送ります。AIがGitHubの制作指示と固定ファイルを読み、そのあと本人の素材で仕上げます。

LPとチラシ・SNS画像は、自分の事業にも、依頼を受けたお客様の仕事にも使えます。

開始文は、配られたファイルを開いて全文をコピーします。Zoomのチャットに貼られた文は途中で切れることがあるので、チャットからはコピーしません。

フォルダの置き方、新しいツールの足し方、配布済みURLの扱い、スキルの編集元は [運用ルール](運用ルール.md) にあります。

## チラシ・SNS画像を作る

できあがるもの: 本人専用の画像制作ツールと、次のPNGです。

| 種類 | サイズ | 使い方 |
| --- | --- | --- |
| チラシ A4 | 2480×3508 | 家庭用プリンタで印刷する |
| SNS 4:5 | 1080×1350 | 縦長のフィード投稿 |
| SNS 正方形 | 1080×1080 | 正方形のフィード投稿 |
| SNS 横長 | 1200×630 | タイムラインとリンクの共有 |

4種類は同じ絵の切り抜きにしません。画面で作る種類と作る案を選べます。全部オンだと12枚です。初めてなら、チラシ1枚とSNS 1枚に絞って帰れます。
