## まず、作りたいものを1つ選ぶ

使う人は、下の「開始文」だけ開けば始められます。開発用フォルダを探す必要はありません。

| 作りたいもの | 最初に開く | できあがるもの |
| --- | --- | --- |
| LP | [LPの開始文](lp/開始文.txt) | 3案を比べて選ぶ完成LP |
| チラシ・SNS画像 | [画像の開始文](flyer-sns/開始文.txt) | 選んだ媒体の完成PNG |
| note記事 | [記事の開始文](note-article/開始文.txt) | 記事・サムネイル・挿入画像 |
| 自分の仕事場 | [マイサイトの開始文](my-site/開始文.txt) | ツールやファイルをまとめるマイサイト |
| 自分用のキャラクター・担当者（第4回） | [キャラクターの開始文](character-studio/開始文.txt) | ペルソナ・役割・プロジェクト指示・最初の依頼文 |

1. 開始文のファイルを開いて、全文をコピーします。
2. ChatGPT Workへ貼り付けます。
3. 作りたい内容や素材を伝え、画面の案内に沿って仕上げます。

Zoomチャットの文は途中で切れることがあるので、配布されたファイルからコピーしてください。
LP・画像・note記事は、マイサイトを先に作らなくても始められます。

手順を見たいとき: [LP](lp/手順.md) / [画像](flyer-sns/手順.md) / [note記事](note-article/手順.md) / [マイサイト](my-site/手順.md)

更新する場所もツール別です：[LP](lp/開発.md) / [画像](flyer-sns/開発.md) / [note](note-article/開発.md) / [マイサイト](my-site/開発.md)。

更新する人はこちら: [どこを編集するか・構成図](docs/repository-map.md) / [運用ルール](運用ルール.md)

## AI向け：チラシ・SNS画像を作るならここを読む

チラシ・SNS画像の開始文は、このリポジトリのURLだけを渡します。個別ファイルの直リンクは使いません。開いたら、次の順で読んでください。

1. この節。
2. [flyer-sns](flyer-sns/README.md) の説明と、[スキルの案内](flyer-sns/スキル.md)。
3. デザインスキル3つ。共通は [design/SKILL.md](releases/workshop2-image-v1/design/SKILL.md)、チラシは [design/FLYER_SKILL.md](releases/workshop2-image-v1/design/FLYER_SKILL.md)、SNSは [design/SNS_SKILL.md](releases/workshop2-image-v1/design/SNS_SKILL.md)。
4. 画面の固定ファイルと制作指示。場所は [releases/workshop2-image-v1](releases/workshop2-image-v1/README.md)。使うファイルは `index.html`、`styles.css`、`app.js`、`consult.js`、`intake.js`、`state.js`、`library.js`、`work.js`、`BUILD_PROMPT.md`。

開始文に書いてある画面の流れ、4サイズ、文字を画像に含める作り方、印刷の余白、材料の聞き方は、リポジトリが読めないときもその文のまま進めてください。読めなかった場所は一言伝え、別の仕様で補わないでください。共有範囲や公開設定は指定しません。

ChatGPT Workで、制作ツールの画面を作り、LPやチラシ・SNS画像を仕上げるキットです。作りたいものを1つ選び、その開始文をWorkへ送ります。AIがこのリポジトリの案内と固定ファイルを読み、そのあと本人の素材で仕上げます。

LPとチラシ・SNS画像は、自分の事業にも、依頼を受けたお客様の仕事にも使えます。

開始文は、配られたファイルを開いて全文をコピーします。Zoomのチャットに貼られた文は途中で切れることがあるので、チャットからはコピーしません。

フォルダの置き方、新しいツールの足し方、配布済みURLの扱い、スキルの編集元は [運用ルール](運用ルール.md) にあります。

## チラシ・SNS画像を作る

できあがるもの: 画像制作ツールの画面と、次のPNGです。

| 種類 | サイズ | 使い方 |
| --- | --- | --- |
| チラシ A4 | 2480×3508 | 家庭用プリンタで印刷する |
| SNS 4:5 | 1080×1350 | 縦長のフィード投稿 |
| SNS 正方形 | 1080×1080 | 正方形のフィード投稿 |
| SNS 横長 | 1200×630 | タイムラインとリンクの共有 |

最初は使う媒体を1つ選び、その媒体で3案を作る進め方にします。ほかの媒体は必要なときに追加します。4種類は同じ絵の切り抜きにせず、媒体ごとに構図を作ります。

配布版によって初期選択が異なる場合は、生成前に媒体を1つに絞ってください。画面自体の初期設定の変更と、この案内の更新は別です。
