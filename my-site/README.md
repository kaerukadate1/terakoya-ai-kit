# マイサイトを作る

Webツール、手元のファイル、スキル、プロンプトを登録する、本人用の仕事場です。

LPやチラシ・SNS画像は、マイサイトがなくても作れます。

## 最初に開くもの

- [開始文](開始文.txt)：Workへ貼る文です。この文はタグ `mytools-v5-20261003-manage` の制作指示を取得します。Zoomのチャットからはコピーしません。
- [手順](手順.md)：初めての人向けです。
- [進行](進行.md)：当日の順番です。
- [スキル](スキル.md)：画面を整えるWebデザインです。

画面と制作指示は [releases/mytools-v5](../releases/mytools-v5/README.md) にあります。フォルダ名は、開始文が取得するパスなので変えていません。

新規のマイサイトは、道具一覧も事業プロフィールも空から始まります。次回の講座案内は、公式サイトの公開情報を表示します。


## 更新する人へ

編集元はこのツールのフォルダ内です。[開発と配布の手順](開発.md)を参照してください。release側は生成物なので直接編集しません。
