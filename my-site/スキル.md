# マイサイトのスキル

マイサイトの画面は、Webデザインのスキルを読んで整えます。編集も、制作指示が取得するのも、プラグイン側です。

| スキル | 場所 |
| --- | --- |
| Webデザイン | [SKILL.md](../plugins/terakoya-ai-creative/skills/terakoya-web-design/SKILL.md) |
| Sitesでの作り方 | [work-sites-guidance.md](../plugins/terakoya-ai-creative/skills/terakoya-web-design/references/work-sites-guidance.md) |

スキルをマイサイトへ登録することはできます。登録は参照先を覚えるだけで、サイトの中では実行もインストールもしません。

新規サイトに見本の登録は入れません。画面のロゴは [terakoya-logo.jpg](../releases/mytools-v5/assets/terakoya-logo.jpg) です。
