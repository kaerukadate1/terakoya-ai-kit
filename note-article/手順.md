# 操作の流れ

1. `開始文.txt`の全文をChatGPT Workへ貼り付けて送信する。
2. Workがビルドプロンプト、画面ファイル、3スキルを読み、本人の新しいツールを作る。
3. 「書きたいことから」または「LPから」を選び、紹介するサービス・読者・使ってよい事実を入力する。
4. アイデア経路はネタ3案から選ぶ。LP経路はおすすめ構成1案へ直接進む。
5. 依頼ボタンで入力済みのChatGPTを開き、Workで送信する。戻った案を事実・未確認事項と照らして確認する。
6. 構成を整え、本文と画像計画を依頼する。同じツールへ返送できた結果はコピー不要で確認画面へ届く。
7. サムネイル・挿入画像を依頼する。同じツールへ返送できた画像は元の位置へ自動で入る。既存画像の差し替えには確認を残す。
8. 完成記事へ保存。本文を書き出し、noteへ貼り付けて見出し・画像・リンクを確認して公開する。

```text
記事アイデア → ネタ3案 → 構成 ┐
LP URL ─────→ おすすめ構成1案 ┴→ 本文・画像 → 完成記事
                           ↑                  |
                           └ Workから同じSiteへ返送 ┘
```

## うまく戻らない時

- 元ツールへ戻り「結果を確認」。15分を過ぎた場合は「再確認」。
- Workが同じSiteを編集・配信できたかを見る。画像が会話に表示されただけでは返送済みではない。
- 依頼後に別の記事へ切り替えたり本文を変更した場合、誤反映防止のため保留する。
- 返送不能なら手動JSONや画像ファイルを使う。権限・共有範囲を緩めて迂回しない。
- 記事・画像はこの端末のブラウザへ保存。重要な記事は画像込みJSONをバックアップする。
