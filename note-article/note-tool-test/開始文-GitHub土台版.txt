寺子屋AI 第3回で使う「note記事を作るツール」を作ってください。

土台は、GitHubの公開リポジトリ kaerukadate1/terakoya-ai-kit（mainブランチ）の note-article フォルダにある既存のツールです。まず次のファイルを実際に取得して読んでください。
・note-article/開始文.txt
・note-article/README.md、開発.md、スキル.md、手順.md、進行.md
・note-article/prompts/（BUILD_PROMPT.md、QA.md、RELEASE_README.md）
・note-article/app/（index.html、styles.css、app.js、core.js、bridge.js、kit.js、assets.js、returns/）
・note-article/skills/（note-writing、note-images、work-return）
・note-article/release/MANIFEST.json と release-map.json

既存ツールの作り・画面の見た目・文言・流れはそのまま保ってください。ゼロから別の画面を作り直したり、デザインを変えたりしないでください。あなた自身で新しくHTMLなどを書き起こすのではなく、既存のapp/のファイルを土台に、次の追加だけを行ってください。

【追加するもの：ボタン3つ】
1.「ChatGPTと相談しながら記事を作る」
2.「今日のニュースから記事を作る」（使う人にニュースを貼らせない。最初に、その人の業務や関心ごとを簡単に聞く。それをもとに、ChatGPT自身がWeb検索で今日のニュースを調べ、記事にする。調べたニュースの出典と日付は、記事の中で確かめられる形で載せる。ニュースや使う人の情報に書かれていない事実は足さない）
3.「学習させる」（使う人の書き方の好みや決まりをChatGPTと整理し、ツールに保存する。保存した決まりは1と2の依頼文の先頭に毎回入る）
どのボタンも、押すと毎回ChatGPT Workが新しく開き、指示文が入力欄に入った状態で始まるようにしてください（自動では送信しない）。既存ツールにあるChatGPTを開く仕組みと同じやり方にしてください。

【文章を整える工程】
記事の本文を書いたあとに、文章を直して自然で読みやすい日本語にする工程を入れてください。仕上げには、同じリポジトリの note-tool-test ブランチにある次のスキルを読んで使ってください。
・note-article/skills/natural-japanese/（SKILL.md と references/）
もう一つのスキル「yomiyasu」は、まだリポジトリに入っていません。中身を推測で作らず、natural-japanese だけを使ってください。
この工程も、押すとChatGPT Workが開き、指示文が入った状態で始まる形にし、整えた結果は確認してから画面に戻せるようにしてください。スキルが読めなかった場合は、推測で代わりを作らず、読めなかったとそのまま伝えてください。
作り終えたら、natural-japanese スキルで大事にしている点を3つ、短く教えてください。

【守ること】
・目的は、第1回で作ったLPへ読者を案内するnote記事を作ること。記事の最後は使う人のサービスやセミナーの案内で締める。
・使う人が入れていない事実・数字・価格・日付・URLを足さない。「収入」という言葉は使わない。
・従量課金のAPIは使わない。自動投稿しない。共有は本人のみ（公開しない）。

【読めなかった場合】
リポジトリやファイルが取得できなかったときは、推測で別のツールを作らず、どのファイルが読めなかったかを伝えて止まってください。

できたら、画面のリンクと、既存ツールから変えた点の一覧を返してください。
