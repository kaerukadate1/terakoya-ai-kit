# 検品と一箇所ずつの修正

| 見る点 | 確認内容 |
|---|---|
| 主題 | 本文と同じ話を伝えるか。主役が分かるか |
| 文字 | 指定した全ての文字が正しく、一度ずつ必要な位置にあるか |
| 可読性 | 原寸と375px程度の表示で見出しが読めるか。周囲が切れないか |
| 構図 | 見る順番が分かり、要素が重ならず、余白があるか |
| シリーズ | 共通の色・質感を保ち、全て同じ絵になっていないか |
| 事実 | 実績・数字・体験を勝手に加えていないか。比較は実際の前後か |
| 保存 | 実寸、容量、PNG、同じSiteと対象記事を確認したか |

点数を適当に付けず、確認できた点と不備を短く記録する。不備がある画像のまま完成と報告しない。

## 編集依頼の型

```text
この画像を編集する。
変更するのは：［誤字／見出しの位置など一つ］
正しい文字列：［必要な場合］
維持するのは：主役、構図、色、光、余白、その他の文字、比率。
別の装飾・人物・文字は加えない。元画像は残して別ファイルへ保存する。
```

変更後は直した箇所と、その周りが変わっていないことを両方確認する。生成を増やすためだけの反復はしない。
