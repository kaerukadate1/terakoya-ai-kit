# 画像の設計を具体的にする

記事を読み、読者が得るもの、描ける場面、使う言葉を先に選ぶ。例えば「第1回LP」は、自分で直せるページと手元のメモ。「第2回」は、同じサービスを紙とスマートフォンで伝える場面。「第3回への変遷」は、LPから画像、文章へつながる流れ。単にAIらしい背景を要求しない。

方向を比べる軸は、主題が一目で分かるか、記事タイトルが読めるか、小さくしても識別できるか。本文に根拠のないストーリーを足さずに選ぶ。

## 生成へ渡す項目

```text
用途：noteサムネイル／本文図解／比較の1枚絵
読者と読む理由：
記事で確認できた内容：
主役と場面：
構図と視線の流れ：
画像内の文字（この文字列を正確に、指定回数だけ）：
光・素材・質感：
シリーズでそろえる点：
余白・切り抜かれる範囲：
実績や体験として描いてはいけないもの：
サイズの目安と背景の透明・不透明：
```

項目を全部埋めることが目的ではない。指定済みの内容は保ち、絵の理解に影響する条件だけ残す。参考画像は役割を付け、顔やロゴの転載許可を推測しない。

複数記事では色と質感を共通にし、主役、視点、紙面の動きを変える。概念図なら関係が読める構造を選び、写真風なら素材や自然光を具体化する。長い本文の要約を画像に詰め込まない。
