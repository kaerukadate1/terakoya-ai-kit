# noteサムネイルと挿入画像

## サムネイル

既定は1280×670px。記事タイトルの全文を詰めず、主題・主役・短い見出しで読む理由を伝える。重要な文字と被写体は中央寄りに置き、一覧のトリミングも考慮する。

文字・写真・イラスト・装飾・余白を一体の画像として設計する。既定のゴシック体を機械的に重ねる方式へ戻さない。生成後に事実の誤記を検査し、必要な箇所だけ修正する。指定色で読みにくくなる場合はコントラストを優先する。

## 本文画像

制作上の既定は1280×720px（note公式の必須サイズではない）。依頼された章の説明が分かりやすくなる図や場面にする。手順図は手順の順番、比較図は比較軸の一致を確認し、本文にない因果・数字・効果を追加しない。

本文と重複する長文ポスターにせず、短いラベルと視覚的な構造を使う。写真風・イラスト風・図解のどれが役割に合うかで選ぶ。

## 共通

- 同じ記事の画像は配色・雰囲気を揃えるが、サムネイルと本文図解を単なるサイズ違いにしない。
- LPの実物を確認できる時だけ絵柄の参考にする。写真・ロゴの転載許可や人物の使用許可を推定しない。
- 実績、数字、顧客の声、人物、資格、効果を勝手に追加しない。
- 最終PNGのピクセルサイズ、誤字、重なり、文字切れ、375px縮小時の可読性を検査。不備があれば修正し、見ていない画像を合格と報告しない。
- 画像は10MB以下。元画像・別依頼の画像は削除しない。依頼された画像1枚だけを制作する。

返送は`work-return/SKILL.md`を読み、対象Siteと依頼IDの画像フォルダへ保存する。チャットに画像を表示しただけでは返送済みにならない。
