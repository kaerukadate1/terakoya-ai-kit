# 寺子屋AI note記事制作ツール / 1.1.1

[開始文](STARTER_PROMPT.txt)をChatGPT Workへ送ると、記事ストック・変更履歴・学習と設定を備えた新しい本人用Siteを作ります。画面とスキルはMANIFEST.jsonの固定ファイルを使います。

## 制作と再利用

- アイデア、LP、相談、ニュースの4つの入口。相談とニュースは構成1案までを返します。
- どの入口も構成・文体・長さ・挿入画像・色を確認してから本文制作へ進みます。制作前には本文と画像制作欄を出しません。
- ニュースは必要なら直近7日へ自動で検索を広げ、出典を構造化して保存・表示します。サービスやURLの案内は任意です。
- 生成した結果は同じ本人用Siteへ保存・配信し、確認画面に戻します。本文と推敲結果は記事ストックにも追記します。
- 記事ストックから読む・コピー・txt/md・バックアップ・続きの編集ができます。以前の本文も残します。
- 入力クリア、学習設定のクリアとリセットには履歴と元に戻す操作があります。
- 学習設定の内容、適用ON/OFF、保存日時、依頼文への反映、新しい記事の初期設定を専用ページで確認・保存できます。

新規Siteではストックと学習設定は空です。本人のSite IDは生成後にmetaへ設定します。講師や他の人のSite・データをコピーしません。

入力・変更履歴・学習設定・手動編集は端末内保存です。WorkがSiteへ保存・配信した本文は同じSiteから読み込みます。別端末で入力や設定も同期されるわけではありません。自動返送は同じSiteを編集・配信できることが条件です。noteへの投稿は本人が行います。

サムネイル1280×670px、本文画像1280×720px。仕上げにnatural-japaneseを同梱しています。

## 開発時の確認

`node --test tests/*.test.cjs`、`node scripts/verify-release.cjs`を実行します。テストの成功と、Workでの新規構築・生成・配信・画面受信の実測は区別して[QA.md](QA.md)へ記録します。
