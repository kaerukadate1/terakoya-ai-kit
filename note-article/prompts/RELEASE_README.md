# 寺子屋AI 第3回 note記事制作ツール

2026-10-23 / 固定配布版 v1.0.1

## 目的

読者の悩みを解決するnote記事から、必要な人が自然にサービスのLPへ進める流れを作る。記事は宣伝だけで終わらせず、単体で役立つ内容にする。

## 操作

1. `dist/index.html`をブラウザで開く。
2. 01で「書きたいことから」または「LPから」を選び、読者・誘導先・使ってよい事実を入力する。
3. アイデアからの場合は「ChatGPTに3案を相談」。依頼文入力済みのChatGPT Workを開き、確認して送信。同じSiteへ保存・配信できた結果は自動で確認画面へ戻る。事実・提案・未確認事項を確認して取り込む。
4. LPからの場合はネタ選びを省略し、構成画面へ直接進む。「ChatGPTでおすすめ構成を作る」で1案を依頼・取り込み、章立て・文体・長さ・画像枚数を調整する。「別の切り口を提案」で別案も依頼できる。
5. 記事制作も依頼文入力済みのChatGPT Workを開く。記事が自動で戻ったら確認して取り込む。本文を直接編集できる。
6. サムネイルと各章の挿入画像をWorkで制作。同じSiteに保存・配信できた画像は元の挿入位置へ自動で戻る。既存画像の差し替えだけは確認を残す。
7. 「完成記事に保存」。再編集、本文・挿入位置の書き出し、画像を含むJSONバックアップが可能。

## 実装済み

- LPと記事アイデアの2つの入口、読者・誘導先・事実・避けたい表現の入力
- ChatGPTへの企画依頼、3案の比較、回答確認、テーマ選択
- LP経路ではネタ選びを省略し、おすすめ構成1案を確認・反映
- 相談・本文・画像制作ボタンから依頼文付きでChatGPTを直接開く（未送信）
- Workから依頼ID別フォルダへの返送。画像の自動挿入、ネタ・構成・本文の自動受信と確認
- 依頼後に変更された記事への誤反映を防止。既存画像の差し替え確認と元に戻す機能
- 構成の編集・並べ替え・追加・削除
- 本文依頼、JSON検証、本文編集とプレビュー
- サムネイルと章ごとの挿入画像計画・生成依頼・ファイル追加
- ブラウザ保存、記事ライブラリ、再編集、本文/挿入位置の書き出し
- 画像込みJSONバックアップの出力と復元
- ライト/ダーク/システム表示

## 境界

- AI処理はChatGPT Workへの依頼式。Workが同じSiteを編集・配信できる場合だけ自動返送される。API接続・永続バックグラウンド自動生成ではない。できない場合は失敗を明示し、手動JSON/画像を予備手段とする。
- LPをブラウザツール自身が直接取得するわけではない。ChatGPTが取得不能なら本文貼り付け・手入力で進め、未確認を明示する。
- 依頼文付きリンクは第2回ツールと同じ`https://chatgpt.com/?prompt=...`方式。ログインや利用環境によって反映されない場合のため、開き直すボタンと手動コピーを残す。長すぎる依頼文（URLが60,000文字超）は省略せず、手動コピーを案内する。
- 本文と設定はlocalStorage、画像はIndexedDB。端末・ブラウザ・サイトのURLが変わると自動同期しない。重要な記事はJSONバックアップを保存する。
- 「一覧から外す」はこのブラウザの記事一覧のみ。note記事や公開サイトは削除しない。
- noteへの投稿・公開は未実装。本人が本文を貼り、見出しを整え、画像を挿入して公開する。
- 画像生成の実行・文章の事実確認・権利確認・最終公開は人による確認を残す。
- 第2回のSite・配布物は変更しない。第3回はGitHubの`releases/note-article-v1/`で独立管理。
