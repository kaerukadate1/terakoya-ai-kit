# note-article を直す人へ

このフォルダ内が編集元です。app/ は画面、prompts/ は制作指示・配布版README、skills/ は本ツールのスキル、tests/ はテストです。実在しない項目の空フォルダは作りません。開始文.txt の既存URLと正本の位置は維持しています。

release-map.json が各正本と従来の配布先を1対1（共用スキルは1対多）で定義します。releases/note-article-v1/ は生成先で直接編集しません。

```sh
node scripts/generate-tool-release.cjs note-article --write
node scripts/generate-tool-release.cjs note-article --check
```

--check（省略時も同じ）は読み取りのみです。--write は明示された対応表だけを書き出し、削除しません。全正本を読んでから書き込みます。今回の移行では配布先の全ファイルをバイト単位で維持しました。

テストと配布スクリプトは従来の配布配置の相対パスを使うため、生成後にrelease側で実行します。編集はこのフォルダ内の正本で行ってください。タグや固定URLの差し替え、Siteの公開設定の変更はこの生成処理に含みません。完成物・顧客情報・Site識別子を追加しません。

Noteのrelease/は既存manifestと配布属性の正本です。今回の整理ではmanifestや固定タグを変更しません。将来機能を変えるときは版更新とハッシュ検証を別工程にします。

検証: node --test releases/note-article-v1/tests/*.test.cjs
検証: node releases/note-article-v1/scripts/verify-release.cjs
