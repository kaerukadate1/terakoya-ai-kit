# note記事を作る

記事アイデア・LP・相談・ニュースから構成を作り、文体・長さ・画像・色を確認してから本文を制作します。完成本文は記事ストックから読み、コピー・書き出し・続きの編集に使えます。

- [開始文](開始文.txt)：参加者がWorkへ貼る全文
- [手順](手順.md) / [進行](進行.md) / [スキル](スキル.md)
- [固定版の制作指示](../releases/note-article-v1/BUILD_PROMPT.md)
- [開発と配布](開発.md)

固定版：`note-article-v1-20261107-title-cover` / 1.2.3。

新しい本人用Siteに、画像付きサンプル1件が入った記事ストックを備えます。変更履歴と学習設定は空で始めます。確認用Siteの記事や設定を参加者へ持ち込みません。Workが同じSiteへ保存・配信できた結果は自動で戻ります。サービス案内は任意。ニュースは適切な当日候補がなければ直近7日へ広げます。

入力・設定・手動編集は端末内、WorkでSiteへ保存した本文は同じSiteから読み込みます。noteへの投稿は本人が行います。

[画像付きサンプル記事](examples/README.md)をGitHubで読めます。
