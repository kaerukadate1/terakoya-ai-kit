# チラシ・SNS画像を作る

チラシとSNS画像を作るツールの画面を作り、媒体ごとに仕上げます。

できた画像は、自分の事業にも、依頼を受けたお客様の仕事にも使えます。

## 出力

| 種類 | サイズ | 使い方 |
| --- | --- | --- |
| チラシ A4 | 2480×3508 | 家庭用プリンタで印刷するPNG |
| SNS 4:5 | 1080×1350 | 縦長のフィード投稿 |
| SNS 正方形 | 1080×1080 | 正方形のフィード投稿 |
| SNS 横長 | 1200×630 | タイムラインとリンクの共有 |

4種類は同じ画像の切り抜きにしません。画面で作る種類と作る案を選べます。全部オンだと3案×4種類で12枚です。チェックを外せば、チラシ1枚とSNS 1枚だけにもできます。

## 最初に開くもの

- [開始文](開始文.txt)：Workへ貼る文です。ドライブに置く原本もこのファイルです。Zoomのチャットからはコピーしません。送ったあとは、AIが質問して材料を集めます。事前の宿題はありません。
- [手順](手順.md)：初めての人向けです。
- [進行](進行.md)：3時間の順番と、チラシ1枚＋SNS 1枚で帰る戻り方です。
- [スキル](スキル.md)：共通、チラシ、SNSの3つです。

当日、場面に合わせてWorkへ貼る文です。開始文と同じく、ファイルを開いて全文をコピーします。
