# 画像ツールを直す人へ

編集する場所は、この flyer-sns/ の中です。

- app/：画面とJavaScript。LP読取入力・JSON返送もここ。
- prompts/：制作指示、既存Site更新指示、配布版README。
- skills/：共通・チラシ・SNSの3スキル。
- tests/：テストの正本。
- 開始文.txt：参加者に配る開始文の正本。URLは変更していません。
- 手順.md・進行.md・README.md・スキル.md：使う人向けの案内。

releases/workshop2-image-v1/ は生成先です。直接編集せず、上の正本を直して次のコマンドを実行します。

```sh
node scripts/generate-flyer-release.cjs --write
node scripts/generate-flyer-release.cjs --check
node --test tests/generate-flyer-release.test.cjs
node --test releases/workshop2-image-v1/tests/*.test.cjs
node releases/workshop2-image-v1/tests/smoke.cjs
node scripts/verify-entrypoints.cjs
```

--check（省略時も同じ）は読み取りだけで、差があれば失敗します。--write は対応表に載る22ファイルだけを更新し、ほかのファイルは削除しません。コピー前にすべての正本を読みます。

tests/ は従来の配布配置に対するテストです。相対パスの互換性を変えないため、生成後に releases/ 側で実行します。テストの修正はこのフォルダ内の tests/ で行います。

今回は既存配布物とバイト単位で同じ状態から編集元だけを分離しました。旧URL・タグ・Siteの公開設定・入力・完成画像は変更しません。画像ツールのpluginは新設していません。LP・note・マイサイトの移行はまだです。

新しいファイルを配布する場合は scripts/generate-flyer-release.cjs の明示的な対応表に追加し、テストの期待数も更新してください。個別Siteの識別情報、顧客入力、完成画像、返送済みJSONを配布対象にしないでください。
